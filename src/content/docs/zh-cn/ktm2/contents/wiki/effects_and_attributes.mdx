# 异界扩展 效果与属性Wiki

更新于 **2026-05-19**。

本页面既是面向玩家的玩法参考，也是针对 异界扩展（IsekaiExpansion）自定义属性和状态效果的开发者参考。

## 公式说明

| 符号                     | 含义                                                                                   | 示例                                                          |
|------------------------|--------------------------------------------------------------------------------------|-------------------------------------------------------------|
| level                  | 状态效果等级，等于 amplifier + 1。状态效果上的原版属性修饰符按 level 缩放。                                     | Amplifier 0 即为 1 级。                                         |
| n(x)                   | CombatAttributeUtil.normalizePercent(x)。如果 abs(x) > 1，代码将其视为百分比并使用 x / 100；否则将其视为比例。 | 25 和 0.25 均表示 25%。                                          |
| hp_ratio               | current_health / max_health，限制在 0 到 1 之间。                                            | 5 HP / 20 HP = 0.25。                                        |
| DataAttributes routing | 来自 data/isekaiexpansion/attributes/functions.json 的属性映射转换。                           | magic_crit_chance 0.05 会为 spell_power:critical_chance 增加 5。 |

## 玩家属性参考

异界扩展（IsekaiExpansion）注册了 40 个 `isekaiexpansion:*` 属性和 7 个自定义的 `spell_power:*` 派系属性。

### 资源与护盾属性

| 属性                                       | 取值范围 / 默认值     | 玩法逻辑                          | 公式                                                            | 示例                         |
|------------------------------------------|----------------|-------------------------------|---------------------------------------------------------------|----------------------------|
| isekaiexpansion:max_energy               | 0~10000，默认 30  | 最大星界能量。如果当前能量超过上限，能量将被限制在上限内。 | max_energy_int = (int) attribute_value                        | 50 让玩家可以持有 50 点能量。         |
| isekaiexpansion:energy_regen_speed       | 0.2~200，默认 0.5 | 控制被动星能回复速率的间隔。数值越高回复越快。       | regen_ticks = (int)(20 / energy_regen_speed)                  | 2 每 10 ticks 恢复 1 点能量。     |
| isekaiexpansion:max_shield_gauge         | 0~1000，默认 75   | 受护盾强效影响前的基础最大盾势值。             | max_gauge = round(max_shield_gauge * shield_power_multiplier) | 100 配合 20% 护盾强效提供 120 盾势值。 |
| isekaiexpansion:shield_gauge_regen_speed | 0.5~10，默认 2    | 控制盾势值回复间隔。数值越高回复越快。           | regen_ticks = max(1, round(20 / shield_gauge_regen_speed))    | 4 每 5 ticks 回复一次。          |

| 属性                                | 取值范围 / 默认值 | 路由目标                        | 公式                      | 示例                            |
|-----------------------------------|------------|-----------------------------|-------------------------|-------------------------------|

| isekaiexpansion:melee_crit_damage | 0~无限制，默认 0 | playerex:melee_crit_damage  | target += value * 0.5   | 0.20 增加 0.10 PlayerEx 近战暴击伤害。 |
| isekaiexpansion:range_crit_chance | 0~无限制，默认 0 | playerex:ranged_crit_chance | target += value * 1.0   | 0.05 增加 5% 弓箭暴击率。             |
| isekaiexpansion:range_crit_damage | 0~无限制，默认 0 | playerex:ranged_crit_damage | target += value * 0.5   | 0.20 增加 0.10 PlayerEx 弓箭暴击伤害。 |
| isekaiexpansion:magic_crit_chance | 0~无限制，默认 0 | spell_power:critical_chance | target += value * 100.0 | 0.05 增加 5 点法术暴击率。             |

### PlayerEx 基础属性包装器

这些属性是直接的流派属性包装器。当 异界扩展（IsekaiExpansion）物品、效果或战利品想要提供 PlayerEx 属性而不直接在物品定义中依赖PlayerEx ID 时，它们非常有用。

| 属性                           | 路由目标                  | 公式                    | 示例          |
|------------------------------|-----------------------|-----------------------|-------------|
| isekaiexpansion:constitution | playerex:constitution | target += value * 1.0 | 6 提供 +6 体质。 |
| isekaiexpansion:strength     | playerex:strength     | target += value * 1.0 | 6 提供 +6 力量。 |
| isekaiexpansion:dexterity    | playerex:dexterity    | target += value * 1.0 | 6 提供 +6 灵巧。 |
| isekaiexpansion:intelligence | playerex:intelligence | target += value * 1.0 | 6 提供 +6 智力。 |
| isekaiexpansion:technique    | playerex:technique    | target += value * 1.0 | 6 提供 +6 技力。 |
| isekaiexpansion:perception   | playerex:perception   | target += value * 1.0 | 6 提供 +6 感知。 |
| isekaiexpansion:belief       | playerex:belief       | target += value * 1.0 | 6 提供 +6 决心。 |

### 自定义法术派系属性

这些属性由 `IsekaiSpellSchools` 创建为 `spell_power:*` 属性，而不是 `isekaiexpansion:*` 属性。每个属性的默认值为 `0`，最小值为 `0`，最大值为 `2048`，并由实体属性系统追踪。

| 属性                               | 法术派系 / 伤害定位 | 玩法逻辑                             | 示例                             |
|----------------------------------|-------------|----------------------------------|--------------------------------|
| spell_power:magic_water          | 水属性         | 根据此派系对自定义水属性法术伤害和治疗规则进行缩放。       | elemental_power 8 会在此处增加 +8。   |
| spell_power:magic_wind           | 风属性         | 缩放自定义风属性法术伤害。                    | 引燃状态对风属性伤害极度脆弱。                |
| spell_power:magic_earth          | 土属性         | 缩放自定义土属性法术伤害。                    | 潮湿状态对土属性伤害极度脆弱。                |
| spell_power:magic_light          | 光属性         | 缩放自定义光属性法术伤害。                    | 暗影状态对光属性伤害极度脆弱。                |
| spell_power:magic_dark           | 暗属性         | 缩放自定义暗属性法术伤害。                    | 光耀状态对暗属性伤害极度脆弱。                |
| spell_power:magic_astral         | 星界          | 缩放自定义星界法术伤害。                     | aether_power 会流入星界法强。          |
| spell_power:magic_physical_melee | 近战物理派系      | 允许 Spell Engine 的伤害表现为类似近战的物理魔法。 | 用于需要将法术伤害路由为近战物理主题时的自定义法术伤害计算。 |

## 状态效果参考

`clearable`（可清除）列指的是 异界扩展（IsekaiExpansion）的自定义清除逻辑。持久性效果（Persistent effects）有更严格的移除规则，如果与另一个持久性效果叠加，可能会触发药水抗药性（potion sickness）逻辑。
