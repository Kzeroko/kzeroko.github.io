# Isekai Expansion Effects & Attributes Wiki

Updated on **2026-05-19**.

This page is both a player-facing gameplay reference and a developer reference for IsekaiExpansion's custom attributes and status effects.

## Formula Notes

| notation                 | meaning                                                                                                                                      | example                                                             |
|--------------------------|----------------------------------------------------------------------------------------------------------------------------------------------|---------------------------------------------------------------------|
| `level`                  | Status effect level, equal to `amplifier + 1`. Vanilla attribute modifiers on status effects scale by `level`.                               | Amplifier `0` is level 1.                                           |
| `n(x)`                   | `CombatAttributeUtil.normalizePercent(x)`. If `abs(x) > 1`, code treats it as percent and uses `x / 100`; otherwise it treats it as a ratio. | `25` and `0.25` both mean 25%.                                      |
| `hp_ratio`               | `current_health / max_health`, clamped from `0` to `1`.                                                                                      | 5 HP / 20 HP = `0.25`.                                              |
| `DataAttributes routing` | Attribute-to-attribute transfer from `data/isekaiexpansion/attributes/functions.json`.                                                       | `magic_crit_chance 0.05` adds `5` to `spell_power:critical_chance`. |

## Player Attribute Reference

IsekaiExpansion registers 40 `isekaiexpansion:*` attributes and 7 custom `spell_power:*` school attributes.

### Resource and Shield Attributes

| attribute                                  | value range / default    | gameplay logic                                                                   | formula                                                         | example                                      |
|--------------------------------------------|--------------------------|----------------------------------------------------------------------------------|-----------------------------------------------------------------|----------------------------------------------|
| `isekaiexpansion:max_energy`               | `0~10000`, default `30`  | Maximum Astral Energy. Energy is clamped down if current energy exceeds the cap. | `max_energy_int = (int) attribute_value`                        | `50` lets the player hold 50 energy.         |
| `isekaiexpansion:energy_regen_speed`       | `0.2~200`, default `0.5` | Controls passive Astral Energy refill interval. Higher is faster.                | `regen_ticks = (int)(20 / energy_regen_speed)`                  | `2` restores 1 energy every 10 ticks.        |
| `isekaiexpansion:max_shield_gauge`         | `0~1000`, default `75`   | Base shield gauge cap before `shield_power`.                                     | `max_gauge = round(max_shield_gauge * shield_power_multiplier)` | `100` with 20% shield power gives 120 gauge. |
| `isekaiexpansion:shield_gauge_regen_speed` | `0.5~10`, default `2`    | Controls shield gauge refill interval. Higher is faster.                         | `regen_ticks = max(1, round(20 / shield_gauge_regen_speed))`    | `4` refills every 5 ticks.                   |

### Combat, Recovery, Threat, and Control Attributes

| attribute                                  | value range / default   | gameplay logic                                                                                                                                                                           | formula                                                                                       | example                                                                    |
|--------------------------------------------|-------------------------|------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|-----------------------------------------------------------------------------------------------|----------------------------------------------------------------------------|
| `isekaiexpansion:ability_haste`            | `-99~500`, default `0`  | Reduces skill cooldowns using haste math. Negative haste lengthens cooldowns.                                                                                                            | `cooldown = round(base * 100 / max(1, 100 + ability_haste))`                                  | `100` haste turns 20s into 10s.                                            |
| `isekaiexpansion:armor_penetration`        | `0~100`, default `0`    | Physical hits ignore part of the target armor input before vanilla armor reduction. Applies to melee/ranged damage categories and non-magic fallback damage.                             | `effective_armor = armor * (1 - clamp(n(value), 0, 1))`                                       | `30` makes 20 armor behave like 14 armor.                                  |
| `isekaiexpansion:magic_penetration`        | `0~100`, default `0`    | Spell damage ignores part of generic Spell Power resistance. It does not reduce school-specific resistance entries.                                                                      | `effective_generic_resistance = resistance * (1 - clamp(n(value), 0, 1))`                     | `0.25` makes 40 generic resistance behave like 30.                         |
| `isekaiexpansion:tenacity`                 | `0~100`, default `0`    | Reduces crowd-control duration and makes hostile effects harder to apply. Reduction is capped at 95%.                                                                                    | `new_duration = round(duration * (1 - clamp(n(value), 0, 0.95)))`                             | `40` turns 5s CC into 3s.                                                  |
| `isekaiexpansion:enmity`                   | `0~100`, default `0`    | Increases outgoing damage at low health.                                                                                                                                                 | `damage *= 1 + n(enmity) * (1 - hp_ratio)`                                                    | `50` at 20% HP gives +40% damage.                                          |
| `isekaiexpansion:stamina`                  | `0~100`, default `0`    | Increases outgoing damage at high health.                                                                                                                                                | `damage *= 1 + n(stamina) * hp_ratio`                                                         | `50` at 80% HP gives +40% damage.                                          |
| `isekaiexpansion:omnivamp`                 | `0~100`, default `0`    | Heals the attacker from post-apply damage. Multiple hits in the same tick after the first use AOE falloff.                                                                               | `heal = dealt_damage * n(value) * falloff`, where `falloff = 1.0` first hit, otherwise `0.22` | `10` heals 2 HP from a 20 damage first hit.                                |
| `isekaiexpansion:shield_power`             | `0~100`, default `0`    | Improves shield gauge cap, shield regen amount, and guard cost efficiency.                                                                                                               | `shield_power_multiplier = max(0.1, 1 + max(0, n(value)))`                                    | `50` gives 1.5x max gauge and regen amount, and divides guard cost by 1.5. |
| `isekaiexpansion:aggro_generation`         | `-100~500`, default `0` | Changes how strongly mobs retarget to the player on hit and during Provoke.                                                                                                              | `aggro_multiplier = max(0, 1 + n(value))`                                                     | `100` doubles Provoke radius pressure; `-100` suppresses it.               |
| `isekaiexpansion:burst_damage`             | `0~1000`, default `0`   | Boosts damage only when the damage source is `isekaiexpansion:ultimate_burst`.                                                                                                           | `damage *= 1 + max(0, n(value))`                                                              | `50` makes ultimate burst damage 1.5x.                                     |
| `isekaiexpansion:energy_leech`             | `0~100`, default `0`    | Restores Astral Energy after spell, melee, or ranged hits.                                                                                                                               | `energy = max(1, round(max_energy * n(value)))`                                               | `10` with 60 max energy restores 6 energy per valid hit.                   |
| `isekaiexpansion:shield_break`             | `0~100`, default `0`    | Increases outgoing damage against a player who is actively guarding with a shield-like item and has usable shield gauge.                                                                 | `damage *= 1 + max(0, n(value))`                                                              | `30` deals 1.3x to an active guard.                                        |
| `isekaiexpansion:evasion_counter`          | `0~1000`, default `0`   | When Dodge/Foresight prevents damage, the defender can counterattack a nearby attacker.                                                                                                  | `counter_damage = max(1, defender_attack_damage * max(0, n(value)))`                          | `50` counters for half of defender attack damage.                          |
| `isekaiexpansion:debuff_accuracy`          | `0~1000`, default `0`   | Improves harmful effect application against Tenacity. At 100% or more, the accuracy roll is forced to pass.                                                                              | `chance = clamp(1 - target_tenacity + n(value), 0.05, 1.0)`                                   | `30` accuracy against 50% tenacity gives 80% application chance.           |
| `isekaiexpansion:guts_chance`              | `0~100`, default `0`    | Gives a passive chance to survive lethal damage at 1 HP if current health was above 25% before the hit. The `death_defiance` buff uses a separate guaranteed lethal-prevention path.     | `if hp_ratio > 0.25 and lethal: roll <= n(guts_chance)`                                       | `20` gives a 20% chance to survive a one-shot from high HP.                |
| `isekaiexpansion:stealth_efficiency`       | `0~100`, default `0`    | Reduces hostile passive target-acquisition radius against the player. It does not forcibly drop enemies already in combat.                                                               | `passive_detect_range = max(2, follow_range * (1 - clamp(n(value), 0, 0.95)))`                | `50` makes a 32 block follow range detect at 16 blocks.                    |
| `isekaiexpansion:environmental_resistance` | `0~100`, default `0`    | Reduces environmental damage from fire/lava, hot floors, freezing, dry-out, cactus, and berry bush. Does not reduce drowning or starvation. Also reduces Inversed Breathing land damage. | `damage *= max(0.05, 1 - clamp(n(value), 0, 0.95))`                                           | `40` reduces lava and freezing tick damage by 40%.                         |
