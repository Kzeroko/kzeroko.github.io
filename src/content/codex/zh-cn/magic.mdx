厄达斯魔法是生灵以自身魔力作为「签名」，让外界魔力按照意图重新排列的共鸣现象。

多数生命都能完成极微弱的魔力操纵，正如多数人都能哼出旋律；要把它变成不会伤害自己和旁人的术式，则需要媒介、训练与对代价的理解。

## 一次法术如何发生

1. **定形**——在体内建立结果的边界。是「让掌心前方三步内的水降温」，不是模糊地想着「变冷」。
2. **共鸣**——以自身魔力接触环境魔力或精魂，请求、交换或强制建立相同波形。
3. **显现**——通过媒介把共鸣释放到现实，并承担热量、反冲、精神负荷或材料消耗。

失败也对应这三个阶段：定形失败让法术偏离目标；共鸣失败通常只浪费魔力；**显现失败最危险**，可能烧毁媒介、伤及施术者，或形成局部魔力污染。

体内魔力不是独立于身体的蓝色燃料。睡眠、营养、情绪、伤势与长期训练都会改变它的容量和恢复速度。强行透支会先出现耳鸣、指尖失温和色觉偏差，继续施法才会损伤魔力回路。

## 魔导体与媒介

媒介负责把高精度控制从施术者身上转移到可重复的材料结构：法杖、法典、刻印、乐器、武器回路与一次性符纸。

**自然魔导体**——魔导水晶、世界树枝、精魂结核与特定魔兽骨骼。魔导水晶来自远古陨星物质与本地地层长期反应，不是无限资源。矿区越深，水晶纯度越高，空间异常与工人魔力病也越常见。

**人工魔导体**——匠人调整合金晶格，使其引导、放大或隔绝特定波形。成熟工坊能做出比天然水晶更稳定的通用导体，却仍需要少量天然材料完成「起振」。矮人炉坊、时钟塔标准与帝国军规使用不同配方，**修理时不可随意混用**。

媒介不是力量来源。失去法杖的法师仍可施法，只是要重新由身体承担精度与反冲；普通人捡到高阶法杖，也不会因此获得对应知识。

## 咏唱

| 形式 | 原理 | 优点 | 代价 |
| --- | --- | --- | --- |
| **请愿式** | 呼唤精魂、说明范围并给予回礼 | 稳定、易教、对天赋要求低 | 时间长，受环境与精魂态度影响 |
| **契约式** | 用预先约定的短句触发固定波形 | 快速，适合战斗与公共设施 | 变化少，需要维护契约或媒介 |
| **命令式** | 施术者以自身理解直接建立法则 | 极快，可临场改变 | 精神负荷高，失败后果严重 |
| **预编式** | 把术式提前写入卷轴、弹匣或魔导器 | 普通人也能使用，结果可测试 | 消耗品成本高，易被封印与干扰 |

无咏唱不等于没有过程。它可能来自身体记忆、预编媒介、极高的控制力，或把咏唱压缩成外人无法感知的精神动作——都不是可以普及给新手的技巧。

## 六元素与高阶学科

大陆把可直接通过自然精魂共鸣的力量称为**六元素**，把需要特殊对象、抽象法则或复合术式的领域称为**高阶学科**。游戏系统沿用十二系分类，但世界内不会把「治愈」误称为自然元素。

| 系别 | 对象 | 常见误解 |
| --- | --- | --- |
| 火 | 热量、燃烧与膨胀 | 不能无代价制造永久热源 |
| 冰 | 结晶、减速与结构固定 | 与水同源，但训练重点不同 |
| 雷 | 电荷、神经冲动与磁力 | 金属会改变路径，不只是增伤标签 |
| 水 | 流体、压力与湿度 | 治疗依靠清洗与循环，不等于生命术 |
| 风 | 气流、声波与压差 | 真空与窒息术受严格管制 |
| 土 | 矿物、土壤与承重结构 | 无法凭空增加可用矿产 |
| 灵魂 | 记忆、意志与生命印记 | 不能证明宗教意义上的死后世界 |
| 治愈 | 组织修复、净化与生命力调度 | 无法替代失去的器官与长期康复 |
| 光 | 光谱、显影与秩序性术式 | 不天然正义，也不专属于教廷 |
| 暗 | 阴影、衰减、诅咒与局部重力 | 不天然邪恶；危险来自难以察觉与解除 |
| 奥秘 | 纯魔力、空间与术式本身 | 是学术分类，不是「什么都能做」 |
| 星界 | 世界边界、相位与宏观重力 | 高负荷、长冷却，受星塔严格监测 |

游戏内的元素克制关系见[元素克制](/zh-cn/wiki/elements/)。

## 精魂

微精魂是自然魔力长期形成的低阶意志模式。它们没有统一语言，也不等同于缩小的人类——火精魂倾向重复扩散，水精魂倾向寻找连续路径。请愿式咏唱正是通过符合这种倾向的节奏与回礼建立短暂合作。

高阶精魂会形成名字、偏好和领地。城市供暖炉、农田引水渠与矿井通风常由固定精魂契约维持。契约中断不只是「魔法坏了」——它也会让负责的家庭失去工作、让街区停水，或迫使居民迁离。
