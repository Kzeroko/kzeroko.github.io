地形配置控制 KTM2 世界生成器的选址、几何、材料与局部气氛。生成过程读取服务端本地快照，修改运行中的配置对象不会重建已有世界，也不会移动已保存的世界树。

## 文件放在哪里

编辑 `config/isekaiexpansion.json` 中的 `terrain` 对象。`autoPatchExoticShaders` 是同一文件中独立的顶层客户端偏好。这些是配置项，不是带命名空间的数据包文件；资源包优先级不决定它们的值。

模组内的 `data/isekaiexpansion/terrain/ktm2.json` 是随包提供的 ReTerraForged 预设，通过模组类路径读取。它不使用本文的配置格式，也不是通常可重载的数据包覆盖入口。集成方式见[地形运行时](/zh-cn/dev/terrain-generation/)。

## 最小示例

将此片段合并到现有配置，保留其他设置。缺失字段使用声明时的初始默认值；不要显式写入 null 对象。

```json
{
  "terrain": {
    "enabled": true
  },
  "autoPatchExoticShaders": true
}
```

## 字段

除首表外，下列路径均相对于 `terrain`。未特别标注单位的几何距离均为格。有限数值与范围检查会拒绝非法值，不会自动钳制。

| 字段 | 类型 | 默认值 | 作用 |
| --- | --- | --- | --- |
| `terrain` | `object` | 下表默认值 | 服务端拥有的世界生成设置，也发送到客户端供展示使用。 |
| `autoPatchExoticShaders` | `boolean` | true | 客户端本地偏好：允许在光影包加载时叠加兼容的着色器源码补丁。 |
| `terrain.enabled` | `boolean` | true | 启用自定义地形、地标选址与装饰；不会移除随包预设或已注册群系。 |

### 选址与共享几何

| 字段 | 类型 | 默认值 | 作用 |
| --- | --- | --- | --- |
| `placement.districtSpacing` | `integer` | 2304 | 区域网格间距，1024–16384 格。 |
| `placement.districtChance` | `number` | 1 | 0–1；每个网格只做一次准入判定，不保证实际生成区域。 |
| `placement.siteAttempts` | `integer` | 64 | 每个网格内、每个系列的分层候选点数，1–128。 |
| `placement.biomeBlendWidth` | `number` | 0.05 | 0.005–0.25；影响过渡宽度预算，地势起伏还可扩大过渡。 |
| `placement.replaceableBiomes` | `array` | 下列 33 个 ID | 允许选址的原始群系精确 ID；空列表不接纳普通区域。未知字符串无法匹配，null 无效。 |

## 校验

方块字符串支持方块状态语法，例如 `minecraft:oak_leaves[persistent=true]`。普通地表字段，以及奇境的 rock/top/soil/crystal/weathered/moss/ice/bone/structure/wood 字段，要求非空气、无流体、无方块实体的实心完整方块。世界树材料使用较宽松的非空气、无流体、无方块实体规则，但 ground 还须通过实心地表校验，glow 必须发光。奇境树叶、花卉、藤蔓与流体另有各行所列的类型要求。

几何校验涉及的数值均须有限且位于范围内。系列尺寸与垂直倍率先独立检查，组合后仍须满足环体容纳与网格边距要求。字段有效不代表区域一定获准生成：生境、可用高度、预留地标与完整形状检查仍可拒绝候选点。

配色列表要求 `1–16` 项，同一系列内 ID 唯一；颜色范围为整数 `0–16777215`。将系列权重设为零或将 `enabled` 设为 false，并不免除构建阶段校验。null 分组、错误方块状态、不支持的骨架类型或非法几何可能中止注册表或世界初始化；不会逐字段静默修复为默认值。

模组的校验器不报告任意未知 JSON 键，不能靠拼错设置名来可靠发现配置错误。空配色列表被拒绝；空替换白名单可被接受，但会阻止普通区域准入。

## 重载

在创建或加载世界前设置生成选项，然后重启以取得新的注册表与生成器快照。`/reload` 不会重新生成地形。这些路径不会重写已生成区块；已保存的世界树预留记录继续使用原坐标与几何。

IsekaiCore `0.4.0-build61` 在登录时同步 `terrain` 对象。生成过程明确读取服务端本地值，气氛展示读取已叠加服务端同步值的活动配置。该桥接不会实时推送修改给已连接客户端。独立的光影开关保持本地控制；Iris 加载光影包时才准备源码覆盖，因此关闭开关会在后续光影包加载时生效。
