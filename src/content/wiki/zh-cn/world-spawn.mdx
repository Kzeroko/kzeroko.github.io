新建的主世界会自己挑选出生点，而不是用原版找到的第一块陆地。它会在离世界中心最远 3072 格的范围内，寻找真正陆块上干燥、较平整的地面，优先选步行可达处有村庄的位置，并避开敌对结构。之后抵达世界出生点的玩家会落在安全的方块上，而不是随机位置。

## 出生点需要满足的条件

下表是默认规则，每个数字都可以在 [世界出生点配置](/zh-cn/wiki/world-spawn-configuration/) 里修改。

| 规则 | 默认值 |
| --- | --- |
| 搜索范围 | 离 `0, 0` 最远 `3072` 格，每 `48` 格采样一次 |
| 地面高度 | 高出海平面 `2–64` 格；高出 `40` 格以上评分降低 |
| 起伏 | `10` 格内高度差不超过 `9` 格 |
| 水域 | 向外 `10` 格和 `24` 格的采样点上都不能有水；`32` 格内采到的水会降低评分，海洋按两倍算 |
| 陆块 | `96` 格和 `192` 格处的陆地采样中，至少 `0.85` 必须是干燥陆地 |
| 距离 | 离中心 `768` 格以内评分完整，再往外 `768` 格评分减半 |
| 村庄 | `64–512` 格外有村庄时，评分最多提高 `35%` |
| 敌对结构 | `160` 格内预测到掠夺者前哨站、林地府邸、远古城市、龙巢、首领竞技场之类的结构时，评分只剩 `10%` |
| 落脚检查 | 最多为最好的 `12` 个候选生成区块，寻找安全方块 |

海洋、河流、蘑菇岛、深暗之域和三种山峰群系永远不会被选中。平原、草甸和风息原野评分最高；沙漠、丛林、沼泽、恶地和积雪群系评分较低。世界树、天环群峰、守望石群岛、苍翠剑脊以及所有奇境地形都被排除。

## 怎么选出生点

搜索只在创建世界时运行一次，而且只针对主世界，分三步进行。

<Steps>

1. **勘测地形**。在带随机偏移的网格上，从中心一圈圈向外给每一列打分，数据直接取自地形生成器，不生成任何区块。每一列在第一条不满足的规则处被排除。当更外圈已经不可能超过现有结果时，勘测就停止；勘测满 `24000` 列后也不再向外扩展。

2. **权衡村庄与威胁**。评分最高的 `32` 列会和结构将要生成的位置比对，同样不生成区块。附近有村庄会加分，附近有敌对结构会大幅扣分。

3. **寻找落脚处**。从最好的一列开始，生成周围 `12` 格的区块，找出最舒适的方块。第一个找得到落脚处的候选就成为出生点。

</Steps>

### 什么算安全方块

落脚处是这一列中除树叶外最高的地面：顶面完整，下方两格内没有流体，上方有两格空间。它还必须是生物能走上去的地方——旁边不能有火、岩浆、水边或会造成伤害的方块。受保护的地标范围内的地面不会被使用。在所有安全方块里，优先选择周围平整、头顶露天、脚下是泥土类方块、并且靠近区域中心的位置。

找到村庄时，世界出生点的朝向会对着村庄。如果创建世界时勾选了奖励箱，奖励箱会放在选出的出生点上。

### 找不到合适位置时

如果没有任何一列符合规则，或者检查过的候选都没有安全方块，服务器日志会写明原因，世界改用原版的出生点选择。配置无效、关闭了出生点选择、或者主世界生成器没有可勘测的地形（例如超平坦世界）时也是一样。调试世界始终使用原版选择。

## 抵达出生点

首次进入的玩家，或者没有床和重生锚而重生的玩家，会落在世界出生点周围 `spawnRadius` 游戏规则范围内的安全方块上。这个方形范围里的每一列都会按打乱的顺序各试一次，第一个安全方块生效。如果一个都没有，就把搜索扩大到世界出生点周围 `24` 格。仍然失败时，交给原版处理。

- **床和重生锚**不受影响，只处理没有重生点的玩家。
- **世界默认游戏模式为冒险模式**时，保持原版的落点。
- **其他维度**保持原版的落点。

## 检查出生点

两条命令都需要权限等级 `2`，无论你在哪个维度，都作用于主世界。`/ise` 是 `/isekaiexpansion` 的简写。

| 命令 | 结果 |
| --- | --- |
| `/ise spawn survey` | 运行勘测和村庄比对，不生成区块。输出勘测的列数、评分最高的 `5` 个候选及其评分和群系，以及每条规则排除了多少列。 |
| `/ise spawn relocate` | 运行完整搜索，按需生成区块，并把世界出生点移到结果处。找不到合适位置时会说明原因，出生点保持不变。 |

每个候选的坐标都可以点击，会填入一条传送命令。标注「附近有聚落」的候选在范围内找到了村庄，标注「附近有敌对结构」的找到了威胁。排除原因对应各条规则：边界外、水域、火山、海拔、地形、群系、临水、起伏、陆块。

<Callout type="caution" title="重新定位会让服务器停顿">
`relocate` 会在服务器主线程上为最多 `12` 个候选生成周围区块。在正在运行的服务器上，这些区块生成期间会出现停顿。
</Callout>

## 其他模组与设置

| 交互 | 行为 |
| --- | --- |
| Biome Spawn Point、Village Spawn Point | 两者都会在这里选好出生点之后再次替换它。安装了其中任何一个时，服务器启动日志会发出警告；想使用这里的规则，就移除它们。 |
| 地形系列 | 按地形系列 ID 打分。风息原野为 `1.2`，流光林地和星辉林间地为 `0.6`，琥珀阶谷为 `0.3`。世界树、天环群峰、守望石群岛、苍翠剑脊和奇境地形被排除。 |
| 没有整合包地形生成器的世界 | 改用原版噪声生成器勘测，地形系列权重不起作用。 |
| 已有的世界 | 保留原来的出生点。可以用 `/ise spawn relocate` 对它们运行搜索。 |

## 设置在哪里

所有规则都在 `config/isekaiexpansion.json` 的 `spawn` 部分，由服务端掌管。每个选项的范围和填错时的后果见 [世界出生点配置](/zh-cn/wiki/world-spawn-configuration/)。打分用到的地形系列见 [地形与地标](/zh-cn/wiki/terrain/)。
