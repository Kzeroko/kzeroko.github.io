IsekaiExpansion 注册了 **44 条 `isekaiexpansion:*` 属性**与 **7 条自定义 `spell_power:*` 学派属性**。下面的范围与默认值都是实际发布的数值。

## 资源与护盾

| 属性 | 范围 / 默认 | 作用 |
| --- | --- | --- |
| `max_energy` | `0–10000`，默认 `30` | 星能上限。当前星能超过上限时会被压回。 |
| `energy_regen_speed` | `0.2–200`，默认 `0.5` | 被动回复间隔，`回复刻 = 20 / 数值`。越高越快。 |
| `max_shield_gauge` | `0–1000`，默认 `75` | 应用 `shield_power` 之前的基础护盾槽。 |
| `shield_gauge_regen_speed` | `0.5–10`，默认 `2` | 护盾槽回复间隔，`max(1, round(20 / 数值))` 刻。 |

## 战斗、恢复、仇恨与控制

| 属性 | 范围 / 默认 | 作用 |
| --- | --- | --- |
| `ability_haste` | `-99–500`，默认 `0` | 按急速公式缩短技能冷却。**负值会拉长冷却**。 |
| `armor_penetration` | `0–100`，默认 `0` | 物理伤害在原版减免前无视部分目标护甲。适用于近战、远程与非魔法回退类别。 |
| `magic_penetration` | `0–100`，默认 `0` | 法术伤害无视部分通用法术抗性。**不**削减按学派细分的抗性条目。 |
| `tenacity` | `0–100`，默认 `0` | 缩短控制时间，并让有害效果更难命中。减免上限 95%。 |
| `enmity` | `0–100`，默认 `0` | **生命值低时**提升输出。 |
| `stamina` | `0–100`，默认 `0` | **生命值高时**提升输出。 |
| `omnivamp` | `0–100`，默认 `0` | 按减免后的伤害回复生命。同一刻内后续命中按 AOE 衰减计算。 |
| `shield_power` | `0–100`，默认 `0` | 提升护盾槽上限、回复量与格挡消耗效率。 |
| `aggro_generation` | `-100–500`，默认 `0` | 命中时与嘲讽期间，怪物切换目标到你身上的强度。 |
| `burst_damage` | `0–1000`，默认 `0` | 仅对来源为 `isekaiexpansion:ultimate_burst` 的伤害生效。 |
| `energy_leech` | `0–100`，默认 `0` | 法术、近战或远程命中后回复星能。 |
| `shield_break` | `0–100`，默认 `0` | 对正在格挡且护盾槽可用的玩家造成额外伤害。 |
| `evasion_counter` | `0–1000`，默认 `0` | 闪避或先见挡下伤害时，防守方可对附近的攻击者反击。 |
| `debuff_accuracy` | `0–1000`，默认 `0` | 让有害效果穿透韧性。达到 100% 或以上时命中判定强制通过。 |
| `guts_chance` | `0–100`，默认 `0` | 在致命伤害下以 1 点生命存活的几率，**且仅在受击前生命高于 25% 时**生效。 |
| `stealth_efficiency` | `0–100`，默认 `0` | 缩小敌对探测范围。100% 时被动索敌完全失效。 |
| `environmental_resistance` | `0–100`，默认 `0` | 减免火焰/岩浆、灼热地面、冻伤、脱水、仙人掌与浆果丛伤害，以及逆呼吸的陆上伤害。**不**减免溺水与饥饿。 |

<Callout type="tip" title="仇恨与耐力是刻意对立的">
它们奖励两种不同的打法，叠在一起收益很差。选那个符合你实际打法的：不挨打的爆发流要耐力，残血硬吃的战士流要仇恨。
</Callout>

## 暴击与法术包装属性

KTM2 的装备只写一个统一的属性名，数值再转到真正实现这套机制的模组上。

| 属性 | 路由到 |
| --- | --- |
| `melee_crit_chance` | `playerex:melee_crit_chance` |
| `melee_crit_damage` | `playerex:melee_crit_damage` |
| `range_crit_chance` | `playerex:ranged_crit_chance` |
| `range_crit_damage` | `playerex:ranged_crit_damage` |
| `magic_crit_chance` | `spell_power:critical_chance` |
| `magic_crit_damage` | `spell_power:critical_damage` |
| `elemental_power` | 火、冰霜、雷、水、风、地 六系法术强度 |
| `dys_aether` | `elemental_power`，外加奥术、灵魂、暗 |
| `aether_power` | `dys_aether`，外加治疗、光、星界 |

最后三条是嵌套的：`aether_power` 覆盖面最广，喂给 `dys_aether`，后者再喂给 `elemental_power`。所以一点以太之力会波及每一个学派。

## PlayerEx 基础属性包装

七条直通包装，均为 `目标 += 数值 × 1.0`：

`constitution`（体质）· `strength`（力量）· `dexterity`（敏捷）· `intelligence`（智力）· `technique`（技巧）· `perception`（感知）· `belief`（信念）

### 元素易伤

这些标记会让目标对特定学派门户大开。其中四种会被直接命中消耗掉，两种会一直留着。

| 效果 | 强易伤 | 轻易伤 | 被直接命中移除 | 附带效果 |
| --- | --- | --- | --- | --- |
| `electrified`（带电） | 冰霜 | 水 | 是 | — |
| `iced`（冰封） | 水 | 雷 | 是 | 每刻为目标灭火 |
| `ignite`（点燃） | 风 | 雷 | 是 | 持续让目标着火 5 秒 |
| `wet`（潮湿） | 地 | 冰霜 | 是 | 每刻为目标灭火 |
| `luminous`（辉光） | 暗 | 奥术 | 否 | — |
| `shadowed`（笼影） | 光 | 奥术 | 否 | — |

<Callout type="tip" title="这就是连携系统">
先挂上易伤，再用对应学派打上去。会被消耗的那四种适合立刻兑现，辉光与笼影会留着，更适合持续施压的打法。
</Callout>
