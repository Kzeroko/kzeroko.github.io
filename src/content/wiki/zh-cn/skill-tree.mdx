命运轮环是共享的主技能树，379 个节点围绕鉴定展开。正常加点最多花费 100 点，因此你需要选择路线与星轨终点能力，而非点满整张图。

## 点数能带来什么

| 项目 | 当前数值 |
| --- | --- |
| 主类别 | `isekaiskills:main`，默认开放 |
| 初始点数 | 1 |
| 玩家等级提升时获得的点数 | IsekaiCore 玩家等级的增量 |
| 正常花费上限 | 100 |
| 根节点 | 鉴定，花费 1；需要手动解锁 |
| 星轨 | 7 条，每条 48 个节点 |
| 共享汇流节点 | 42 个，与根节点及星轨节点并列 |

从等级 1 正常成长时，初始点数加升级所得点数，使可用总预算与玩家等级相同，直至正常花费上限。原版经验等级不会提供这些点数。其他点数来源或管理员操作可能改变已储存的总点数。

鉴定授予 `isekaiskills:spassive_appraisal`，供集成系统识别的被动标记。它本身不增加属性，也不实现信息查看浮层；浮层能显示哪些信息，取决于读取此标记的集成。

## 选择星轨

| 星轨 | 主属性 | 中途被动 | 终点能力（互斥） |
| --- | --- | --- | --- |
| 守御 | 体质 | 不坏之躯 | 世界之锚 / 守护者神盾 |
| 战印 | 力量 | 斗争本能 | 弑巨者 / 战神回响 |
| 疾风 | 灵巧 | 弓手律动 | 贯穿天际 / 逐风者 |
| 月刃 | 技力 | 无瑕架势 | 千锻慧眼 / 无血之刃 |
| 先见 | 感知 | 第六感 | 因果视界 / 猎命笃定 |
| 星术 | 智力 | 星脉回路 | 大魔导公式 / 魔力君王 |
| 圣域 | 决心 | 慈悲之心 | 圣者之约 / 奇迹编织者 |

每条星轨分为 5 阶。每阶路线从入口节点经过深层节点、织式，再通向阶段关口。内置树的交汇处只需满足 **1 条入边路线**；有多条连线，不代表必须买齐所有前置节点。

以下关口还要求 IsekaiCore 玩家等级，以及在**整个类别**中已花费的点数。累计花费在购买当前节点之前检查。

| 关口 | 玩家等级 | 已花费点数 | 节点花费 |
| --- | --- | --- | --- |
| 第 1 阶 | 10 | 8 | 2 |
| 第 2 阶：中途被动 | 20 | 17 | 3 |
| 第 3 阶 | 35 | 32 | 2 |
| 第 4 阶 | 50 | 47 | 2 |
| 第 5 阶 | 70 | 67 | 2 |
| 任一终点能力 | 90 | 82 | 8 |

同一星轨的终点能力互斥。在其他星轨的花费可以计入整个类别的累计花费门槛，但不能代替入边路线或玩家等级要求。

汇流节点连接表中相邻的星轨，末尾的圣域与开头的守御相邻。由内向外，其等级要求依次为 5、15、25、42、60、80。每个花费 2，给予相邻主属性各 +1。它们是路线终点：购买汇流不会开启通往另一条星轨的路线。

买齐一条星轨全部可选节点、鉴定以及 1 个终点能力，共需 90 点。这是整条星轨的花费，不是到达终点的最短路线花费。整张图的节点标价合计 764 点；每组排除 1 个终点能力后仍需 708 点，远超正常预算。

## 可习得主动能力

| 星轨 | 主动能力 | 能力 ID |
| --- | --- | --- |
| 守御 | 王域·不落神盾 | `isekaiskills:active_aegis_domain` |
| 战印 | 勇者突袭 | `isekaiskills:active_heroic_rush` |
| 疾风 | 坠星箭雨 | `isekaiskills:active_starfall_volley` |
| 月刃 | 千重刃界 | `isekaiskills:active_thousandfold_edge` |
| 先见 | 天启刻印 | `isekaiskills:active_providence_mark` |
| 星术 | 星界新星 | `isekaiskills:active_astral_nova` |
| 圣域 | 圣域显现 | `isekaiskills:active_sanctuary` |

每项能力有 3 级。节点位于第 3、4、5 阶，分别要求玩家等级 30、50、70；路线开放后，节点本身花费 0 点。重复解锁会提升同一项能力的等级。

这些能力目前**没有战斗效果**。配置的冷却与星界能量消耗均为 0；解锁或装入习得技能栏，不会获得名称所暗示的攻击、防护或治疗。等级与技能栏对接已存在，但实际效果为空。

## 使用技能树界面

按绑定的技能树按键打开界面。选择节点可查看花费、前置、本地条件与互斥关系；在可解锁节点上持续按住鼠标主键，或按住 Enter、Space，达到 1.2 秒后发起解锁请求。

| 操作或状态 | 行为 |
| --- | --- |
| 拖动 | 平移；移动超过 5 个界面单位会取消长按 |
| 鼠标滚轮 | 围绕指针缩放 |
| 方向键 | 选择对应方向的邻近节点 |
| Home | 适配整张图 |
| `=` / `-` | 放大 / 缩小 |
| 搜索 | 匹配本地化标题与说明，并循环定位结果 |
| Escape 或技能树按键 | 关闭；文本框获得焦点时，技能树按键不会关闭界面 |
| 请求等待中 | 暂停后续解锁，最多等待 5 秒确认 |

松开按键、离开图形区域、失去焦点、切换类别或不再满足条件，都会取消尚未完成的长按。长按完成只会提交请求；只有观察到服务器将节点置为已解锁，才播放解锁动画。超时表示未观察到确认，不代表服务器已回滚请求。

界面每 150 毫秒刷新一次快照。不可访问的类别仍会显示，但无法解锁。种族、职业与职业限制能力的门槛可作用于其他类别，不会让共享主技能树变成某一种族或职业专属。

## 成长与其他系统

| 变化 | 对技能树的影响 |
| --- | --- |
| 玩家等级提升 | 向主技能树增加等级差值对应的点数 |
| 玩家等级回退 | 重置主技能树解锁，并将自动点数设为新等级减 1 |
| 玩家等级重置 | 清除主类别的存档状态 |
| 不再满足某项条件 | 阻止新的解锁；该检查本身不会撤销已解锁节点 |
| 重载条件数据 | 服务器使用新条件；重新连接可更新客户端条件目录 |
| 习得技能栏 | 主动能力等级使用同一习得能力来源，并与技能栏状态协调 |
