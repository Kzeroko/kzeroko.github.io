每个阵营独立记录你的声望，范围为 −1000 至 +1000，初始值为 0。声望不高于 −100 时，该阵营将你视为通缉对象；每次变化都依据对应阵营自己的当前声望计算。

## 哪些行为改变声望

| 事件 | 基础变化 | 条件 |
| --- | --- | --- |
| 取走受保护物品被发现 | −10 至 −20 | −(10 + 2 × max(0, 目击者 − 1))，下限为 −20；目击者位于 16 格内。 |
| 伤害阵营成员 | −2 至 −12 | −clamp(2 + floor(伤害 × 0.5), 2, 12)；无需目击者。无效或非正伤害不扣声望。 |
| 击杀阵营成员被目击 | −45 至 −70 | −clamp(40 + 5 × 目击者, 40, 70)；目击者位于 32 格内。 |
| 击杀守护者正在攻击的怪物 | +5 | 存活守护者位于 32 格搜索盒内，且以该怪物为目标。 |
| 击杀怪物以解救村民 | +10 | 怪物正以村民为目标，或 24 格搜索盒内的村民处于恐慌状态且威胁记忆指向该怪物。 |
| 同时满足两种防卫条件 | +15 | 每次击杀各奖励只加一次，不按受保护实体数量累加。 |

偷窃按玩家、容器位置与维度分别设有 100 刻（5 秒）冷却。伤害事件按玩家、受害者与维度分别设有 200 刻（10 秒）冷却。创造及旁观模式玩家不参与这些偷窃与战斗事件；任务奖励有独立入口。

### 目击者与受影响阵营

每次最多计入 6 名目击者。他们必须存活、清醒，且没有失明、黑暗或魅惑效果。偷窃目击者须与受保护容器共享阵营，能看见玩家，且双方眼部之间无遮挡。击杀目击者须与受害者共享阵营、能看见凶手，并与受害者之间保持无遮挡视线。

偷窃影响容器的受保护阵营与目击者所属阵营。击杀阵营成员只影响受害者与目击者共有的阵营。伤害直接影响受害者所属阵营。防卫奖励归入守护者与获救村民所属阵营。

针对 `isekaiexpansion:side/monster` 与 `isekaiexpansion:side/undead` 的战斗扣分，在对应声望为正时生效。声望为 0 时，只有文明阵营不敌视该阵营才扣分；低于 0 时过滤掉扣分。此例外仅作用于伤害及被目击的击杀，不覆盖所有声望变化。

## 受保护容器

通过容器界面取走物品可能触发偷窃；仅打开容器不会。玩家放置的物品容器对所有玩家都豁免，不区分放置者。生成的容器可在填充战利品时记录阵营归属。没有标记的容器会回退到所在地的城市及村庄阵营。

双容器根据物品所在槽位对应的一侧确定位置与归属。在村庄中放置的玩家箱子，不会因填充战利品而变成村庄财产。没有合格目击者时，取走受保护物品不会产生这里的偷窃扣分。

## 阵营与关系

实体归属综合显式指定、NPC 配置及匹配的数据规则。规则还可以包含已保存的结构来源阵营。实体仅仅走进聚落，不会自动加入其阵营。

关系依次取持久化运行时覆盖、数据包规则，最后才按共有阵营视为友好，否则中立。规则优先级越高越先采用；相同优先级冲突时，敌对优先于友好，友好优先于中立。这些关系与个人声望数值相互独立。

仅在选取战斗目标时，没有显式归属提供者、NPC 配置或匹配阵营规则的敌对或怪物类别实体，会获得 `isekaiexpansion:side/monster`。普通玩家不会自动获得阵营选敌否决。该回退规则并不意味着击杀所有怪物都会触发声望事件。

## 通缉阵营与命运天平

[命运天平](/zh-cn/wiki/fate-balance/)的面相选项，只在受影响阵营已经通缉你时调整本次变化。

| 命运抉择 | 正向变化 | 负向变化 |
| --- | --- | --- |
| `kind_countenance` — 面相和善 | ×1.25 | ×0.80 |
| `fierce_countenance` — 面相狰狞 | ×0.80 | ×1.25 |

结果按运行时取整规则取最近整数；非零变化至少保留 +1 或 −1。每个阵营分别调整，最终声望再限制在上下界。首次跨过 −100 的变化不会追溯应用面相修正。

村庄相关变化还会写入原版的少量正面或负面流言。该桥接最多处理 12 名村民，优先直接参与者，再搜索 48 格盒形区域；流言幅度最多为 25。它不会替代阵营声望记录。

## 阅读声望报告

报告列出默认阵营及你已有记录的动态归属。聚落名称由阵营 ID 确定，但不是唯一标识。聚落描述依据请求报告时你的位置提供方位；其他维度会单独说明。

| 声望标签 | 范围 |
| --- | --- |
| 敬仰 | 750–1000 |
| 尊敬 | 400–749 |
| 友善 | 100–399 |
| 中立 | −99–99 |
| 戒备 | −399–−100 |
| 敌视 | −749–−400 |
| 仇恨 | −1000–−750 |

这些是显示区间；通缉阈值仍为 −100。名称与描述由服务端组装，并随当前数值发送。

## 数据来源

实体归属与阵营关系位于 `data/<namespace>/reputation/`。[声望数据](/zh-cn/wiki/reputation-data/)提供完整字段表；[声望运行时](/zh-cn/dev/reputation-runtime/)说明持久化、事件钩子与报告组装。
