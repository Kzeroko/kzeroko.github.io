成年武器匠、工具匠或盔甲匠可通过对话接受已揭示蓝图。确认委托后，订单保管蓝图并立即收取全部报价；制作完成时，成品与蓝图一并交还。

铁匠会分段说明价钱、工期和约定。逐段听完后才会出现最后的答复；挑选图纸时使用图纸列表自己的确认按钮。

## 委托需要什么

| 规则 | 数值 |
| --- | --- |
| 同时持有订单 | 每位玩家全服 1 单；每位铁匠 1 单。 |
| 蓝图 | 已揭示、放在主物品栏中，且对应有效锻造配方与产物。 |
| 工作天数 | 蓝图指定 2–30 个每日工作额度。 |
| 每日工作量 | 2–6 个游戏小时；每小时为 1000 刻，正常刻速下为 50 秒。 |
| 工作时段 | 每个 24000 刻游戏日中的第 2000–8999 刻。 |
| 对话距离 | 不超过 8 格。 |
| 工作站范围 | 铁匠周围 48 格内，且存在可达路径。 |
| 货币显示 | 100 铜币 = 1 银币；100 银币 = 1 金币。 |

内置钻石剑蓝图报价为 24000 铜币，即 2 金币与 40 银币，需工作 3 天、每天 4 小时。这表示必须完成的实际工作量，不保证经过相应日历天数就能交货。委托按报价制作指定产物，不会从你的物品栏扣除锻造材料。

## 提交委托

与符合条件的铁匠交谈，在委托菜单选择蓝图，核对产物、价格与工作安排后确认。铁匠必须存活、清醒、可使用 AI、未受威胁，并与你处于同一世界；玩家必须存活且不在旁观模式。

铁匠需要属于自己的、符合职业的工作站。旁边放着尚未认领的工作站并不足够。付款通过 IsekaiCore 提供的 Numismatic Overhaul 联动处理；缺少联动或付款失败时，不会接受订单，蓝图仍留在物品栏。

村民流言也会影响菜单访问：负面重大与次要流言绝对值合计达到 50 时视为不受欢迎，达到 100 时拒绝交谈。它与[阵营声望](/zh-cn/wiki/reputation/)分别计算。

## 何时推进工作

铁匠必须实际抵达指定工作站、与工作站之间具有可交互视线，并处在白天工作时段。交谈、危险、睡眠、禁用 AI、工作站缺失或道路受阻均可能暂停进度。用完当天额度后，需要等到后续游戏日。

跳过时间或关闭服务器不会补发工作量。将日期调回过去，可能使铁匠等待至存档记录的工作日。服务器最多维护 8 个远程工坊加载租约；已加载区域中的铁匠仍可独立工作，不受该租约数量直接限制。

## 领取、转交与取消

| 操作 | 结果 |
| --- | --- |
| 领取 | 到负责该订单的铁匠处，一并取回成品与蓝图。主物品栏必须能同时容纳两者。 |
| 转交 | 交给空闲、符合条件且工作站可达的铁匠。保留进度、当天已用额度、产物和报价，不另收费；已完成订单也可转交。 |
| 取消 | 未完成时，可在符合交互条件的铁匠处取回蓝图。已付费用不退，也不提供成品。 |
| 物品栏已满 | 暂不领取或取消，订单继续保留。 |
| 已有订单 | 查看当前状态，不能再提交另一张蓝图。 |

转交也可用于更新原铁匠的工作站。原铁匠失踪后，另一位符合条件的铁匠仍能显示你的全服订单，并提供转交或取消操作。已完成订单只能领取，不能取消。
