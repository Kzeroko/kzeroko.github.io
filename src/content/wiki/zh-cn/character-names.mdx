姓名目录收录完整的幻想姓名，每个都有英文与简体中文。首次创建角色时，可以选用预设，也可以自己输入。普通NPC也会从这些姓名文化中取名。

## 姓名文化

目录保存的是包含姓氏的固定全名。不同条目可以共用名字，NPC之间也可能重名。

| 文化 | 默认选择 |
| --- | --- |
| 异世界·西陆 | 人类及没有匹配规则的身份。 |
| 精灵·银叶林 | 精灵。 |
| 矮人·炉火厅 | 矮人。 |
| 兽人·自由边境 | 猫人。 |
| 龙裔·苍烬群峰 | 龙族及进阶龙族分支。 |
| 灵裔·梦花庭 | 史莱姆与翼灵。 |
| 海民·明珠群岛 | 人鱼。 |
| 夜裔·绯绒宫 | 恶魔。 |
| 大和·月见诸国 | 大和文化；没有文化覆盖时也用于狐人与鬼人。 |
| 东煌·玉川诸州 | 东煌文化。 |

文化优先于种族默认规则。东煌狐人使用东煌姓名，大和狐人使用大和姓名。内容作者还可以为指定的种族与文化组合单独设置姓名池。

## 挑选姓名

在「基础」页的「寻觅姓名」中选择文化，再筛选女性、男性或中性姓名。初始筛选跟随角色性别，选姓名不会改变性别或种族。「适合我的角色」使用创建界面当前已知的种族；尚未选择起源时，使用西陆默认池。

搜索同时匹配当前显示的姓名和罗马字标识符，每页最多显示8个。「随机选取」会从全部搜索结果中抽取，包含其他页面。也可以随时编辑姓名输入框；输入后，这个名字会改为自定义文本。

预设姓名按每位查看者的语言显示。手动输入的姓名保持原文，最多48个UTF-16单位，并过滤格式符和控制字符。显示开关可以暂时改用账号名，同时保留角色姓名。账号身份、命令和权限仍使用账号名。

角色头顶的名称牌与状态界面同样使用所选姓名。查看已登记的公会名牌时，如果持有人已经加载，便显示其当前姓名，也会反映登记后的改名；持有人未加载时，显示登记时保存的可翻译姓名。名牌中的半身证件照按圆角边框裁切。持有人已加载时，显示其自定义角色外观与装备；未加载时，使用对应账号皮肤的三维替身。照片是睁眼的静态照，随卡片一起倾斜，重新打开名牌时刷新。较早原型格式的名牌需要重新登记。

赞助者加入与离开播报使用当前角色姓名，预设姓名按查看者的语言显示。加入播报读取登录前保存的姓名；尚未选择角色姓名时，使用账号名。

## 恢复单项默认值

选项旁的小回转箭头用于恢复默认值。滑块回到轨道标记的默认位置，部件恢复为当前性别与种族适用的默认部件，颜色重置只影响当前选中的通道或联动组。姓名重置会清空角色姓名，并恢复显示账号名。

这些重置都能撤销。「还原」仍回到打开编辑器时的外观，不会把全部项目恢复为出厂默认值。

## NPC姓名

无名的非独特异界扩展NPC会在加载时自动取名，默认也包含村民和流浪商人。对Guard Villagers的支持通过可选实体类型标签提供，无需安装该第三方模组也能使用命名系统。

独特角色与已有自定义名称的实体保留原名。契约经纪人与公会接待员使用「姓名 · 职业」格式。命名不会逐刻执行，文化改变也不会自动改名。已分配的可翻译姓名保存在实体中，重新加载后仍然保留。

对话中，NPC 尚未信任你时只显示职业或类型。达到信任后，对话标题与 `{name}` 标记显示全名，包括已经保存的职业后缀。每次打开对话都会按当前玩家检查关系；仅有隶属归属不会揭示姓名。村民及未接入信任判断的其他 NPC 继续显示职业。独特角色同样使用职业称呼，例如伊维莉娜在此时显示为探求的魔导师。

此规则只影响对话显示，不修改实体姓名，也不隐藏世界中的名称牌。

## 设置与内容

服务器命名设置分别控制自动命名、村民、标签指定的第三方NPC、功能NPC职业后缀，以及玩家预设姓名。关闭自动命名不会清除已有姓名；关闭玩家预设后，仍可手动输入。

异界扩展的「赞助者播报」设置由服务器控制，分别设置加入播报、离开播报、动作栏显示、显示自己的加入播报，以及加入提示音。启用本人播报时只显示一次；离开播报仅发送给仍在线的玩家，不播放声音。这组设置现由异界扩展管理，赞助资格仍由异界核心判断。

完整姓名目录只保存在游戏资源中。本页说明文化分类与行为，不复制姓名清单，也不维护持续变化的数量统计。

姓名池、翻译与实体标签见[姓名池数据](/zh-cn/wiki/name-pools/)。角色外观使用[人形与NPC预设](/zh-cn/wiki/humanoid-presets/)。
