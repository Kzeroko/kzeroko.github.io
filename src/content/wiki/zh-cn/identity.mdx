种族、职业与技艺分别占据独立的身份层。进阶系统记录各层中已解锁的身份，让你重返旧身份时不必再次支付其条件消耗。

## 现有内容

| 身份层 | 身份层 ID | 内置进阶图 |
| --- | --- | --- |
| 种族 | `origins:origin` | 进化：11 个基础身份与 7 个进阶龙分支。 |
| 职业 | `origins-classes:class` | 晋升：7 个互不连接的基础身份。 |
| 技艺 | `isekaiprofessions:profession` | 晋升：3 个互不连接的基础身份。 |

种族图中只有龙系组成连通分支。其他基础种族均为独立节点；职业与技艺图当前没有可沿连接切换的身份。界面只显示当前身份所在的连通分支。

从 `isekaiorigins:dragon` 出发，内置分支通向：

| 目标身份 | 额外条件 |
| --- | --- |
| `isekaiorigins:raevyx` | 无 |
| `isekaiorigins:stegonaut` | 无 |
| `isekaiorigins:cindervane` | 无 |
| `isekaiorigins:varasuchus` | 无 |
| `isekaiorigins:ignivorus` | 无 |
| `isekaiorigins:volitans` | 无 |
| `isekaiorigins:atroxiia` | 无 |

以上是内置图的定义。服务器数据包可替换它们并增加条件，因此确认前应查看所在服务器的节点详情。

## 打开与操作进阶图

点击状态界面的“查看成长路径”进入种族图，再选择种族、职业或技艺章节。选择节点后可查看描述与条件。拖动背景平移，用滚轮或缩放按钮调整大小，重置视图可回到中心；重置视图不会清除进度。

| 节点状态 | 含义 |
| --- | --- |
| 当前路径 | 正在使用的身份，不能重复激活。 |
| 已解锁 | 已记录在历史中；仍连通且符合资格时可重新激活。 |
| 可解锁 | 当前满足前置与条件，提交时服务端仍会重新检查。 |
| 未解锁 | 当前不满足首次解锁条件。 |

在可用或已解锁节点上按住鼠标主键。内置节点需要 30 刻（1.5 秒），数据包可设为 10–200 刻（0.5–10 秒）。提前松开或移出节点会取消；长按完成时就会发送请求，无须等到松开。

此界面不会暂停世界。服务端会话持续 1200 刻（60 秒），重新打开会创建新会话。服务器数据重载成功后，旧会话失效；若提示请求过期或无效，请重新打开界面。

## 解锁与重返

首次解锁时，**全部入边前置节点**都必须是当前节点或已解锁节点。目标至少要有一个入边前置。解锁后，离开的身份与选择的身份都会被记录。

重返已记录身份会跳过其前置与消耗，但它仍须与当前身份连通，并符合服务器当前定义的资格。因此可以返回基础龙身份，也可在已解锁的龙分支间切换；不能借此选择不连通的职业或种族。

节点可要求以下条件：

| 条件 | 所需内容 | 是否可消耗 |
| --- | --- | --- |
| 玩家等级 | Isekai Core 玩家等级达到门槛。 | 否 |
| 经验等级 | 原版经验等级达到门槛。 | 是；若列为消耗，会扣除等级。 |
| 进度 | 完成指定进度。 | 否 |
| 物品 | 背包中有足量的已注册物品。 | 是；须列为消耗。 |

全部条件通过后才支付。创造模式跳过物品数量检查与所有消耗，但仍须满足等级和进度条件。重返已解锁节点不会重复收费。

## 身份转换期间

服务端受理请求时，先保存解锁记录并支付首次解锁消耗，再开始视觉转换。正常的服务端时间线如下：

| 阶段 | 时长或时间点 |
| --- | --- |
| 节点受理效果 | 转换开始前持续 12 刻（0.6 秒）。 |
| 转换与操作锁定 | 受理效果之后持续 64 刻（3.2 秒）。 |
| 身份生效 | 转换开始后 26 刻（1.3 秒）。 |
| 身份显现 | 转换开始后 38 刻（1.9 秒）。 |
| 完整流程 | 从受理起共 76 刻（3.8 秒）。 |

界面关闭，镜头移到角色身后，转换期间锁定物品使用、攻击、移动与跳跃。流程结束时，若镜头仍处于流程设置的视角，就恢复先前视角。

断线或目标资格失效可能中断流程。已支付消耗与已保存解锁不会回滚。若身份尚未生效，重连后可重新打开界面，在目标再次符合资格时激活已记录节点；重返不会再次收费。

## 与其他系统的关系

| 系统 | 交互 |
| --- | --- |
| Origin 能力 | 应用目标会改变身份，并重新协调技能配置。 |
| 变身 | 身份变化会协调当前变身。详情可预览所选目标授予形态的外观变体，但选择变体须已拥有该形态的变身能力。 |
| 解锁历史 | 重生保留解锁。数据包重命名图或节点不会迁移旧历史；删除连接可能使旧解锁无法到达。 |

形态外观变体与进阶解锁分别保存。预览目标或变体不会授予对应身份。

## 定义位置

服务端图位于 `data/<namespace>/progression_graphs/<path>.json`。[身份进阶图数据](/zh-cn/wiki/progression-data/)说明全部字段、前置条件与重载规则；[变身数据](/zh-cn/wiki/morph-data/)介绍身份可授予的能力与形态。
