宝石资源决定能抽到哪些加成，以及能镶嵌到哪些装备上。服务端将所有宝石类别作为一个快照加载；任意资源无效时，保留原快照。

## 文件放在哪里

除全局设置外，下列路径均相对于 `data/<namespace>/`，任意命名空间均可提供定义。全局设置只读取 `data/isekaiexpansion/gem_system/settings.json`。

```text
gem_system/settings.json
gem_attributes/random_roll/*.json
gem_attributes/fixed_attributes/*.json
gem_attributes/element_attributes/*.json
gem_attributes/skill_attributes/*.json
socket_profiles/*.json
curses/*.json
gem_consumables/*.json
```

每个文件包含一个对象。高优先级数据包覆盖相同命名空间及路径的资源；不同路径的定义仍会检查 ID、属性及物品归属是否重复。全局设置取最高优先级资源，不逐字段合并。插槽配置 ID 是 `socket_profiles/` 下的相对路径加命名空间，并去掉 `.json`。

## 最小示例

保存为 `data/example/socket_profiles/iron_sword.json`。它为铁剑提供一个已解锁的属性插槽，并覆盖自带近战配置。显式优先级避免示例被现有配置遮蔽；解析器本身不要求填写。

```json
{
  "priority": 120,
  "match": {
    "items": [
      "minecraft:iron_sword"
    ]
  },
  "sockets": [
    {
      "kind": "ATTRIBUTE",
      "min_item_level": 0
    }
  ]
}
```

## 字段

使用真正的 JSON 数字与布尔值。缺少必填字段或数值转换失败会导致重载失败。除“校验”列出的已移除字段外，未知字段会被忽略。错误容器类型的回退行为在表中明确列出。

### 全局设置

| 字段 | 类型 | 默认值 | 作用 |
| --- | --- | --- | --- |
| `random_roll_count` | `array<object>` | `[{count:1,weight:80},{count:2,weight:17},{count:3,weight:3}]` | 按权重抽取词条数量。缺失、非数组、空数组或所有权重为零时使用默认表。 |
| `random_roll_count[].count` | `integer` | `1` | 正整数；实际词条数不超过可抽取的不同属性数量。 |
| `random_roll_count[].weight` | `integer` | `0` | 非负；零权重条目会被移除。 |
| `random_requirement_roll` | `object` | `{}` | 控制随机宝石是否获得装备限制。 |
| `random_requirement_roll.base_chance` | `number` | `0.42` | 有限概率 0–1；没有难度上下文或对应覆盖值时使用。 |
| `random_requirement_roll.dungeon_difficulty_chances` | `object` | `{}` | 难度到概率的映射，有限值 0–1。键为 common、uncommon、rare、epic、legendary、unique。 |
| `random_requirement_pool` | `array<object>` | `[]` | 装备限制候选。空数组表示不会抽到限制。 |
| `random_requirement_pool[].id` | `identifier` | 必填 | 唯一限制 ID；存入宝石，并用于生成翻译键。 |
| `random_requirement_pool[].weight` | `integer` | `1` | 非负默认权重；此值或至少一个难度覆盖权重必须大于零。 |
| `random_requirement_pool[].dungeon_difficulty_weights` | `object` | `{}` | 使用相同难度键；覆盖默认权重，值必须是精确的非负整数。 |
| `random_requirement_pool[].match` | `object` | 必填 | 至少包含一种限制；所有非空限制组必须同时满足。 |
| `random_requirement_pool[].match.items` | `array<item id>` | `[]` | 物品须在列表中；只校验 ID 语法，不要求对应物品已注册。 |
| `random_requirement_pool[].match.all_tags` | `array<tag id>` | `[]` | 须符合全部标签；可省略开头的 #。 |
| `random_requirement_pool[].match.any_tags` | `array<tag id>` | `[]` | 至少符合一个所列标签。 |
| `random_requirement_pool[].match.weapon_types` | `array<string>` | `[]` | 须符合一个解析出的武器类型；完整列表见下文。 |
| `random_requirement_pool[].match.nbt` | `array<object>` | `[]` | 须符合全部 NBT 条件。 |
| `random_requirement_pool[].match.nbt[].path` | `string` | 必填 | 非空的复合标签键路径，以点分隔；不支持空路径段或列表索引。 |
| `random_requirement_pool[].match.nbt[].regex` | `string` | 必填 | 有效且非空的正则表达式，最长 512 字符。匹配整个值字符串；输入超过 4096 字符时不匹配。 |
| `insert` | `object` | `{}` | 镶嵌设置；非对象时使用默认值。 |
| `insert.base_success` | `number` | `0.85` | 有限值 0–1，不得大于 success_cap。 |
| `insert.success_cap` | `number` | `0.95` | 有限值 0–1，表示镶嵌概率上限。 |
| `insert.crack_chance_on_fail` | `number` | `0.2` | 有限概率 0–1，仅在镶嵌失败后判定裂损。 |
| `insert.fatigue` | `object` | `{}` | 整件装备共享的镶嵌调谐负荷；非对象时使用默认值。 |
| `insert.fatigue.max` | `integer` | `10` | 非负的调谐负荷储存上限。 |
| `insert.fatigue.on_fail_add` | `integer` | `1` | 有效镶嵌尝试失败时增加的调谐负荷，不得为负。 |
| `insert.fatigue.on_success_change` | `integer` | `-2` | 成功时的调谐负荷变化，不得为正；结果限制在 0–max。 |
| `insert.fatigue.success_bonus_curve` | `object` | `{}` | 非对象时使用默认值。 |
| `insert.fatigue.success_bonus_curve.type` | `enum(LINEAR)` | `LINEAR` | 忽略首尾空格和大小写；其他曲线会导致重载失败。 |
| `insert.fatigue.success_bonus_curve.per_fatigue` | `number` | `0.06` | 每点调谐负荷增加的概率，须为有限非负值。 |

| `modifiers[].operations[].value` | `number` | 必填 | 有限固定值，按 format 舍入。 |
| `modifiers[].operations[].format` | `object` | `{decimals:2}` | 使用相同舍入格式。 |
| `modifiers[].operations[].difficulty_scaling` | `object` | `{}` | 使用相同难度缩放格式。 |

### 枚举与公式

武器限制接受 `none`, `sword`, `rapier`, `greatsword`, `glaive`, `dagger`, `lance`, `scythe`, `axe`, `halberd`, `spear`, `mace`, `hammer`, `wand`, `staff`, `katana`, `chakram`, `gauntlet`, `boomerang`, `bow`, `crossbow`, `gun`, `magigun`。忽略大小写及首尾空格；未知名称导致重载失败。

公式计算倍率，再对 `base × multiplier` 应用舍入格式。`areaLv` 与 `level` 都是区域等级；`base` 与 `value` 都是未缩放属性值。公式分组与装备限制映射的难度键不同：

| 地牢难度 | 公式分组 |
| --- | --- |
| `common`、`uncommon` | `common` |
| `rare`、`epic` | `default` |
| `legendary` | `dangerous` |
| `unique` | `mythic` |

没有对应分组时回退到 `default`。缺少公式、结果非有限或求值出错时，倍率为 1；求值错误在使用时记录，不在重载阶段报错。公式由依赖 exp4j 求值。公式键与表达式的网络传输上限分别为 64 和 512 字符；即使加载时未检查，也应遵守。缩放只作用于随机与固定属性，不作用于元素或技能宝石。

### 耗材动作

下列 ID 均使用 `isekaiexpansion:` 命名空间；动作字段放在 `data` 内。

| 动作 | 效果 |
| --- | --- |
| `isekaiexpansion:reroll_random_lines` | 重洗随机属性、数值及装备限制。 |
| `isekaiexpansion:reroll_random_values` | 保留属性、操作及装备限制，重洗数值。 |
| `isekaiexpansion:reroll_socketed_random_gems` | 重洗插槽中的随机宝石；排除锁定或裂纹插槽。 |
| `isekaiexpansion:remove_socketed_gem` | 按 break_chance 判定碎裂并取出；锁定会阻止取出，裂纹不会。 |
| `isekaiexpansion:extract_safe` | 以零碎裂概率取出。 |
| `isekaiexpansion:set_socket_state` | 达到等级要求后修改空插槽的封印。 |
| `isekaiexpansion:reroll_socket_kind` | 将空、未锁定、无裂纹的插槽改成其他类别。 |
| `isekaiexpansion:apply_curse` | 为没有诅咒的目标绑定诅咒。 |
| `isekaiexpansion:cleanse_curse` | 移除已有诅咒数据。 |
| `isekaiexpansion:repair_crack` | 修复已达到等级要求的裂纹插槽；允许处于封印状态。 |
| `isekaiexpansion:reduce_insert_fatigue` | 降低装备已有的调谐负荷。 |

判定与消耗前，先检查两个分支是否存在可用动作。选中的分支按顺序执行；后续动作无效时，已经完成的修改不回滚。判定成功但没有有效动作时，不消耗物品。判定失败且规则为 `ALWAYS` 时，即使失败分支为空也可能消耗。空目标永远不可用。新增代码动作时，仅注册动作并不会增加适用性规则。

诅咒属性值与状态持续时间乘以储存的倍率。承伤变为 `damage × (1 + sum(value × curse multiplier))`；效果等级不缩放。多个诅咒提供相同状态效果时，持续时间与等级取最大值，ambient 按 OR 合并，粒子与图标可见性按 AND 合并。

## 完整示例

保存为 `data/example/gem_attributes/random_roll/attack_damage.json` 前，先替换或移除其他使用相同属性的随机定义。它采用自带随机文件的结构；不同文件名不能绕过属性 ID 的唯一性检查。

```json
{
  "attribute": "minecraft:generic.attack_damage",
  "domain": "OFFENSE",
  "weight": 1,
  "damage_categories": [
    "MELEE"
  ],
  "operations": [
    {
      "name": "ADDITION",
      "min": 1,
      "max": 2,
      "format": {
        "decimals": 2
      },
      "difficulty_scaling": {
        "formula": "1 + areaLv * 0.02",
        "min_multiplier": 1,
        "max_multiplier": 2
      }
    }
  ]
}
```

## 校验

- **格式错误、空文件或非对象文件：** 记录资源错误并拒绝新快照；要求非空的数组不得留空。
- **未知注册 ID：** 宝石物品、属性、学派、效果与可触发技能会导致重载失败。插槽和装备限制的物品／标签筛选只校验语法；可选模组不存在时保持为不匹配条件。
- **重复定义：** 重复随机属性 ID、同类定义 ID、同类物品 ID，以及固定／元素／技能类别间共用物品都会导致重载失败。相同优先级的配置合法，按 ID 排序。
- **范围无效：** 有限值、概率及正数检查会拒绝数据，不会自动钳制。部分整数字段使用数值转换，应明确填写整数。难度权重映射还拒绝小数及仅大小写不同的重复键。
- **已移除字段：** `insert.cost_curve` 被拒绝，改用 `insert.crack_chance_on_fail`；元素 `extras` 被拒绝，改用明确的元素字段。
- **条件兼容：** 解析宝石字段前检查 Fabric 的 `fabric:load_conditions`。条件失败时排除文件；设置文件条件失败则使用默认值。条件语法属于 Fabric，通过条件后仍严格校验注册 ID。

未知动作字段通常忽略；`set_socket_state` 会将不认识的键复制到存档状态。可选动作字段类型错误时，可能绕过读取器并回退而非报错。JSON 动作数据转换为 NBT：布尔值变为 byte，整数范围内的整数变为 int，其他数值变为 double，null 变为空字符串。数组应使用相同元素类型。

限制的翻译键为 `gem_requirement.<namespace>.<path>`，路径斜杠替换为点。删除限制定义后，已有宝石储存的该 ID 将无法匹配装备，不会自动解除限制。

## 重载

服务端资源重载时加载宝石资源。玩家加入时收到当前快照；数据包重载成功后广播给已连接客户端。替换时清空物品到插槽配置的缓存。宝石自身校验失败会保留原快照，但不代表其他重载监听器也具有统一事务。

物品 NBT 单独保存。重载不会重洗已有随机数值，却可能改变兼容性、固定定义数值及物品使用的配置。减少插槽数量后，下次修改操作规范化物品时可能丢弃多余的存档插槽；修改前应检查已有镶嵌装备。
