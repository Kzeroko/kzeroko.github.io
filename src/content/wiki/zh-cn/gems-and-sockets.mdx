装备的镶嵌槽来自它的**镶嵌配置**。每个槽位只接受一种宝石，四种槽位分工不同。

<Callout type="caution" title="原型阶段">
宝石系统是一套可用的原型，只有一份当前 schema，不会迁移已经移除的数据结构。格式变动时，附带的数据会在同一次提交里一起改。
</Callout>

## 四种槽位

| 槽位 | 接受 |
| --- | --- |
| `ATTRIBUTE` | 带 1–3 条随机属性词条的可熔合宝石 |
| `FIXED` | 带预定义加成的具名材质宝石 |
| `ELEMENT` | 以指定魔法学派造成伤害的战斗触发 |
| `SKILL` | 被动触发，或可手动激活的装备技能 |

槽位规则还能再收窄：限制属性域、伤害类别、魔法学派、具体技能，或最低物品等级。**宝石必须满足该槽位的每一条限制**，光是种类对上不够。

## 镶嵌

把兼容的宝石拿到光标上，对着带槽的装备使用。有多个可用槽位时，会弹出选择界面。

内置规则：

| 规则 | 数值 |
| --- | --- |
| 基础成功率 | 85% |
| 成功率上限 | 95% |
| 失败增加 | 1 点共鸣负荷 |
| 每点负荷 | 为下一次增加 6 个百分点 |
| 成功移除 | 2 点负荷，最低为 0 |
| 失败可能使槽位开裂 | 20% |
| 失败是否消耗宝石 | 否 |
| 成功是否消耗宝石 | 是 |

```text
成功率 = min(上限, 基础成功率 + 负荷 × 每点加成)
```

<Callout type="tip" title="这是有上限的保底">
失败会让后续尝试更容易，但不会让镶嵌变成必定成功。连续失败五次把成功率从 85% 抬到 95%，然后就停在那里。
</Callout>

## 锁定、封印与开裂

**锁定**的槽位无法镶嵌、激活、重铸或释放宝石。有两种锁定来源：

- **配置锁**，在装备达到该槽位的最低物品等级时解除；
- **持久封印**，记录在物品上，槽位为空时可用工匠透镜切换。

**开裂**的槽位是禁用的：属性加成与战斗触发都不再生效，用金缮树脂修好之前也放不进新宝石。已经在里面的宝石会留在原处，仍然可以取出。

## 读提示框

装备提示框始终列出各槽位，并给出「按住 Shift 查看槽位详情」的提示。按住 <kbd>Shift</kbd> 后，底部会补充：

- 当前与最大共鸣负荷；
- 下一次镶嵌的成功率；
- 锁定与开裂的槽位数量；
- 已附加的诅咒及其掷出的倍率。

元素与技能宝石会显示各自的触发条件与冷却。**只有随机战斗触发才显示概率**：手动激活的技能一定会触发，没有概率可言。

## 取出

| 工具 | 行为 |
| --- | --- |
| 宝石切割器 | 取出所选宝石，有 50% 几率使其碎裂 |
| 秘银宝石切割器 | 安全取出 |
| 虚空凿 | 消耗品，有风险的取出 |
| 以太卡尺 | 消耗品，安全取出 |

锁定的槽位阻止取出，开裂的槽位不会。

## 消耗品

消耗品会在掷点和消耗物品**之前**先检查一遍。用不上的消耗品什么也不做，也不会被用掉。

| 物品 | 效果 |
| --- | --- |
| 混沌棱镜 | 替换随机属性宝石上的全部词条与数值 |
| 完美之尘 | 保留属性与运算方式，只重掷数值 |
| 熵之十二面体 | 替换已镶嵌的某颗随机宝石的词条 |
| 虚空凿 | 按配置的碎裂风险取出所选宝石 |
| 以太卡尺 | 安全取出所选宝石 |
| 工匠透镜 | 在空槽位的「封印」与「开放」之间切换 |
| 变异黏土 | 把一个空的、开放的、完好的槽位改成另一种类型 |
| 血契羽笔 | 为未被诅咒的带槽装备附加一个配置好的诅咒 |
| 圣化之灰 | 移除装备上的诅咒 |
| 金缮树脂 | 修复所选的开裂槽位 |
| 谐律之油 | 降低共鸣负荷 |

重铸会保留宝石记录的难度信息，所以在高难度环境里得到的宝石，重铸之后依然按高难度算。

## 战斗触发

| 触发 | 触发时机 |
| --- | --- |
| `MELEE_HIT` | 命中近战 |
| `RANGED_HIT` | 命中远程 |
| `MAGIC_HIT` | 命中法术 |
| `ON_HURT` | 受到伤害 |
| `ON_KILL` | 击杀目标 |
| `TRIGGERABLE` | 手动激活——**仅限技能宝石** |

元素宝石不能使用 `TRIGGERABLE`。手动技能宝石使用自己的装备技能按键、星能消耗、按槽位计算的冷却，以及装备搜索优先级。

## 诅咒

一件装备最多绑定一个诅咒，强度在诅咒定义的倍率区间里掷。内置的负面类型有：

- 负向属性修正；
- 周期性的有害状态效果；
- 提高受到的伤害。

诅咒效果从防具、双手与已装备的饰品上一并收集。提示框会显示诅咒及其掷出的倍率。

## 内置镶嵌进程

配置按优先级从高到低求值，第一个匹配的生效。

| 装备类别 | 槽位进程 |
| --- | --- |
| 遗物 | 0 级：属性 |
| 防具 | 0 级：属性；10 级：固定 |
| 盾牌 | 0 级：固定；10 级：属性 |
| IsekaiCore 盾牌 | 0 级与 10 级：属性 |
| 近战武器 | 0 级与 10 级：属性；20 级：近战元素 |
| 远程武器 | 0 级与 10 级：属性；20 级：远程元素 |
| 法杖与长杖 | 0 级：属性；10 级：魔法元素；20 级：技能 |
| 工具 | 0 级：属性 |
| 折纸・天野夜樱 | 0 级：属性；20 级：技能 |

这里的数字是[装备等级](/zh-cn/wiki/leveling/)。这也是「专心养一把武器」最实在的理由：法杖要到装备等级 20 才能开出技能槽。

## 给数据包作者

所有路径都在 `data/isekaiexpansion/` 之下：

```text
gem_system/settings.json
gem_attributes/random_roll/*.json
gem_attributes/fixed_attributes/*.json
gem_attributes/element_attributes/*.json
gem_attributes/skill_attributes/*.json
socket_profiles/*.json
curses/*.json
gem_consumables/*.json
```

重载是**全有或全无**的：所有宝石资源先整体校验，只要有一份非法，这一次重载就整体作废，原来的配置继续生效。校验通过后，完整配置会同步给所有客户端。

### 跨模组定义

每一份宝石 JSON 资源都支持 Fabric 标准的 `fabric:load_conditions`。请使用加载条件，而不是注册替代物品或放宽注册表校验：

```json
"fabric:load_conditions": [
  { "condition": "fabric:all_mods_loaded", "values": ["jewelry"] }
]
```

条件不匹配的资源会被有意排除。如果所需模组**确实**已加载，那么其中引用的每一个物品与注册表条目仍会被严格校验。内置的黄水晶、翡翠、红宝石、蓝宝石、坦桑石与黄玉属于 Jewelry 兼容内容，只在存在 `jewelry` 模组时加载。

### 本地化

宝石文本只能放在 `language_assemble/categories/gem/en_us.json` 与 `…/zh_cn.json`。汇编任务会拒绝跨分类的重复键，因此名字相似但不属于本系统的物品（例如 `gem_ofcursedocean`）应留在它自己的分类里。
