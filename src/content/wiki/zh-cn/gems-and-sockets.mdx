宝石为兼容插槽的装备提供属性、元素伤害或技能。每个插槽容纳 1 个宝石，类别与解锁等级由装备配置决定；宝石本身还可能带有适用装备限制。

## 各类插槽提供什么

| 类别 | 收益 |
| --- | --- |
| `ATTRIBUTE` | 聚熔宝石的随机属性。自带词条数量为 1、2、3，对应权重 80:17:3。 |
| `FIXED` | 预定义属性加成，部分会随宝石来源的战利品难度缩放。 |
| `ELEMENT` | 战斗触发时造成指定法术学派的伤害。 |
| `SKILL` | 战斗触发或手动激活的装备技能。 |

随机与固定宝石须符合属性域和伤害类别；元素宝石须符合学派和伤害类别；技能宝石须符合技能白名单。随机宝石的全部词条都要通过检查。“适用对象”限制也必须匹配装备，镶嵌后仍会检查。

## 镶嵌宝石

将宝石拿在光标上，左键点击可用装备，再选择插槽。只有 1 个可用插槽时也会打开界面。成功消耗 1 个宝石，失败保留宝石；关闭界面后返还剩余来源物品。

| 自带镶嵌规则 | 数值 |
| --- | --- |
| 基础概率 | 85% |
| 概率上限 | 95% |
| 失败增加负荷 | 1 |
| 每点负荷的概率加成 | +6 个百分点 |
| 成功减少负荷 | 2，最低 0 |
| 储存负荷上限 | 10 |
| 失败后的裂纹概率 | 20% |

调谐负荷属于整件装备，由全部插槽共享。从 0 开始，下次成功率为 85%；失败 1 次后为 91%，失败 2 次后达到 95%。继续失败也不会超过 95%。只有镶嵌失败后，才进行 20% 的裂纹判定。

在装备提示上按住 <kbd>Shift</kbd> 可查看负荷、下次成功率、插槽状态数量及诅咒详情。

## 锁定、裂纹与取出

达到所需[装备等级](/zh-cn/wiki/leveling/)后，等级锁解除。封印是另一种持久锁定；达到等级要求且为空的插槽可用巧匠透镜切换封印。

锁定或裂纹插槽都不能接受宝石，也不提供宝石属性／触发。已有宝石会留在裂纹插槽内。裂纹允许取出，锁定阻止取出；重新镶嵌前需用金缮凝脂修复裂纹。

| 取出工具 | 结果 |
| --- | --- |
| 嵌石小刀 | 所选宝石有 50% 概率碎裂。 |
| 秘银嵌石小刀 | 安全取出。 |
| 虚空蚀凿 | 消耗品取出，宝石有 50% 概率碎裂。 |
| 以太相位规 | 消耗品安全取出。 |

非创造模式使用小刀会消耗耐久。取出宝石后，插槽已保存的冷却仍保留。

## 耗材

不适用的耗材不会生效，也不会消耗。自带耗材的动作判定必定成功；虚空蚀凿仍有独立的碎裂判定。

| 物品 | 效果 |
| --- | --- |
| 混沌棱晶 | 重洗随机词条、数值及装备限制。 |
| 至臻尘埃 | 保留属性、操作及装备限制，重洗数值。 |
| 熵变魔骰 | 重洗所选已镶嵌随机宝石，包括装备限制。 |
| 虚空蚀凿 | 取出宝石，有 50% 概率碎裂。 |
| 以太相位规 | 安全取出。 |
| 巧匠透镜 | 达到等级要求后切换空插槽封印。 |
| 幻变灵泥 | 将空、未锁定、无裂纹的插槽改成其他类别。 |
| 血契翎笔 | 为没有诅咒的装备绑定一个随机配置诅咒。 |
| 祝圣余烬 | 移除已绑定诅咒。 |
| 金缮凝脂 | 达到等级要求后修复裂纹；封印不会阻止修复。 |
| 谐律灵油 | 减少 1 点调谐负荷，最低为 0。 |

重洗保留已存难度上下文，并从未缩放基础值重新应用缩放。替换词条还可能改变适用装备限制。谐律灵油降低负荷，也会降低该负荷提供的镶嵌概率加成。

## 战斗与主动技能

| 触发 | 扫描装备 |
| --- | --- |
| `MELEE_HIT`、`RANGED_HIT`、`MAGIC_HIT` | 对应伤害类别的攻击者双手。 |
| `ON_KILL` | 击杀者双手。 |
| `ON_HURT` | 受击者防具及双手。 |
| `TRIGGERABLE` | 主动技能依次检查主手、副手、头、胸、腿、脚。 |

战斗宝石触发不扫描饰品。技能宝石要求使用者是玩家，并可能消耗星界能量。冷却按插槽独立保存；元素宝石不能使用 `TRIGGERABLE`。

主动激活通过冷却与能量检查后不再判定概率。按上述顺序选择第一个兼容宝石，同件装备内取第一个插槽。若它正在冷却或能量不足，不会跳到后面的宝石。操作按键见[装备技能](/zh-cn/wiki/equipment-skills/)。

## 诅咒

每件装备可绑定 1 个诅咒。储存的强度缩放属性惩罚、状态持续时间或承伤加成。诅咒的状态／承伤效果扫描防具、双手及饰品，范围比战斗宝石触发更广。祝圣余烬可移除已绑定诅咒。

## 自带插槽进程

配置按优先级从高到低、再按 ID 排序，第一个匹配项生效。下表描述自带配置；自定义数据包或重叠物品标签可能改变结果。

| 装备组 | 类别与最低装备等级 |
| --- | --- |
| 符合遗物／饰品标签的物品 | 0 级 `ATTRIBUTE`；配置排除降落伞、Create 护目镜、Backpacked 背包及灯笼。 |
| 防具 | 0 级 `ATTRIBUTE`，10 级 `FIXED`。 |
| 盾牌 | 0 级 `FIXED`，10 级 `ATTRIBUTE`。 |
| IsekaiCore 盾牌 | 0、10 级 `ATTRIBUTE`。 |
| 近战武器 | 0、10 级 `ATTRIBUTE`，20 级近战 `ELEMENT`。 |
| 远程武器 | 0、10 级 `ATTRIBUTE`，20 级远程 `ELEMENT`。 |
| 魔杖与法杖 | 0 级 `ATTRIBUTE`，10 级魔法 `ELEMENT`，20 级 `SKILL`。 |
| 工具 | 0 级 `ATTRIBUTE`。 |
| `isekaiexpansion:origami_amanoyozakura` | 0 级 `ATTRIBUTE`，20 级 `SKILL`。 |

## 数据放在哪里

规则来自 `gem_system`、`gem_attributes`、`socket_profiles`、`curses` 与 `gem_consumables` 数据资源。[宝石数据](/zh-cn/wiki/gem-data/)列出全部字段、条件兼容、校验及重载行为。
