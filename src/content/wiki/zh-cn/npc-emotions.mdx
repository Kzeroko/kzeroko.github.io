具名 NPC 会对伤害、赠礼、消耗品和当前活动产生情绪反应。心情表示当前状态，性格则决定反应强弱与恢复速度；心情强度不是好感度。

## 心情表示什么

每种心情分别保存即时反应、持续记忆和情境影响，各自范围为 0–100。显示强度取三者之和，最多 100；主心情是经过激活门槛与切换规则选出的当前状态。

| 心情 | 名称 | 常见来源或含义 |
| --- | --- | --- |
| `composed` | 平静 | 没有更强活跃心情时的平静基线。 |
| `joyful` | 喜悦 | 正向礼物及食物、饮品带来的喜悦。 |
| `affectionate` | 亲昵 | 正向赠礼引起的亲昵，受依恋倾向影响。 |
| `flustered` | 慌羞 | 赠礼引起的慌羞或情绪流露。 |
| `excited` | 兴奋 | 战斗、攻击和消耗品引起的兴奋。 |
| `focused` | 专注 | 活动点工作与战斗带来的专注。 |
| `bored` | 无聊 | 没有其他活动时持续闲置产生的无聊。 |
| `uneasy` | 不安 | 受伤、危险及战斗中低生命状态带来的不安。 |
| `hurt` | 心伤 | 友好或受信任玩家造成伤害后的心伤。 |
| `angry` | 愤怒 | 受伤及敌对反应引起的愤怒。 |
| `exhausted` | 疲惫 | 低生命状态及其残留影响带来的疲惫。 |

普通市民和非具名 NPC 没有这套持续情绪模拟，对话中报告 `composed`、强度 0，且没有次心情。身体表情动作和表情贴纸是另外的表现系统，不能据此推断心情强度。

## 什么会改变心情

| 情况 | 反应 |
| --- | --- |
| 正向赠礼 | 增加喜悦、亲昵、慌羞，并缓解无聊、心伤、愤怒。 |
| 接受了好感增量为 0 的礼物 | 短暂慌羞并轻微缓解无聊；这不表示拒绝礼物。 |
| 进食或饮用 | 少量喜悦与兴奋，缓解无聊和疲惫。 |
| 执行攻击 | 短暂兴奋与专注，缓解无聊。 |
| 友好或受信任玩家造成伤害 | 引起心伤与愤怒。 |
| 其他伤害 | 引起不安；来自其他存活实体时还会引起愤怒。 |
| 战斗中受伤 | 还可增加兴奋；严重低生命状态会增加疲惫和不安。 |

这些是实际事件反应，单纯靠近玩家不会持续生成亲昵或喜悦。正向事件可以减轻负面强度，但不会直接清除全部长期记忆。

### 当前处境

| 条件 | 基础情境目标 |
| --- | --- |
| 普通状态 | 平静 9 |
| 睡眠 | 平静 22 |
| 活动点工作中 | 专注 34 × 活力 |
| 战斗中 | 专注 16 × 勇气；兴奋 23 × 活力 × 勇气 |
| 未睡眠且生命比例低于 0.50 | 疲惫 38 × 危险程度；战斗中另有不安 25 × 危险程度 × 勇气反向系数 |
| 持续无活动 | 闲置超过 25 次每秒采样后，经过 100 次采样逐渐达到无聊 30 × 活力 |

危险程度为 `(0.50 - 生命比例) / 0.50`。性格还会缩放各心情目标；重叠来源取较大值。对话、活动点、战斗、使用物品、睡眠或移动都会打断无聊积累。未加载期间不会按离线时长累积闲置采样次数。

## 恢复与切换

即时反应恢复较快，记忆恢复较慢，均按强度线性下降；情境强度逐渐趋近当前目标。安抚先减少即时反应，再减少情境，最后减少记忆。不同性格和心情的恢复速度不同。

| 规则 | 数值 |
| --- | --- |
| 情境更新与常规主心情判断 | 每 20 tick（1 秒） |
| 明显领先即可提前切换的差值 | 3.5 强度 |
| 保留当前心情的最短等待条件 | 60 tick（3 秒）；明显领先或当前低于门槛可提前切换 |
| 加载后按世界时间补算恢复的上限 | 7 天 |
| 每次情境趋近最多采用的时间 | 2 秒 |

主心情之外，还可保留最强的其他活跃非平静心情作为次心情。一次赠礼后仍有心伤，并不意味着赠礼没有生效；它可能只降低了尚未完全恢复的强度。

## 对话可读取的信息

以下元数据由 NPC 对话提供，属于读取结果，不是可以放进数据包的心情配置文件。表中回退值描述无情绪模拟时的结果；性格仍取角色自身配置。

| 字段 | 类型 | 默认值 | 含义 |
| --- | --- | --- | --- |
| `isekaiexpansion:npc_mood_key` | string | `composed` | 主心情键。 |
| `isekaiexpansion:npc_mood_intensity` | float | `0` | 主心情强度除以 100，限制为 0–1。 |
| `isekaiexpansion:npc_secondary_mood_key` | string | `""` | 其他活跃非平静心情中最强者，没有则为空。 |
| `isekaiexpansion:npc_secondary_mood_intensity` | float | `0` | 次心情强度除以 100，限制为 0–1。 |
| `isekaiexpansion:npc_personality_key` | string | `default` | 配置的性格键，与当前心情独立。 |

对话使用稳定字符串键；不要将界面名称或内部序号当作键。非 NPC 对话不由此提供器添加这些字段。

## 数值来源与相关页面

心情和性格数值内置于模组，没有可通过 `/reload` 替换的专用心情 JSON 目录。若需改变公式或性格配置，请阅读 [NPC 情绪运行时](/zh-cn/dev/npc-emotion/)；[表情贴纸数据](/zh-cn/wiki/emoji-data/)说明独立的贴纸资源格式。
