命运天平用默认10点起始点数塑造日常生活。恩赐消耗点数，负契最多额外提供6点。饮食、睡眠、性格与交往特质共用这份预算。

## 点数预算

| 规则 | 数值 |
| --- | --- |
| 起始点数 | 默认`10`；服务端设置`fateBalanceMaxPoints`，范围`0–64` |
| 负契贡献上限 | `6` |
| 剩余点数 | 起始点数+负契贡献−恩赐消耗 |
| 确认条件 | 剩余点数至少`0`，并满足可用性、前置、冲突与互斥组规则 |
| 空命谱 | 允许，也可以保留未花费点数 |

每对对立命途不能并选。全部口味命途共用一个互斥组，因此口味恩赐与负契合计最多选一条。食物标签没有任何物品时，对应口味不可选。分类为通用、起居、心性、交往、饮食与特殊。

## 编织命谱

先选择命途查看效果，再将其选入或释放。添加冲突命途前，先移除已有选择。撤销与重做修改草稿；重置恢复打开编辑器时的命谱。预设替换草稿，仍需确认。

定下命谱时，服务端会再次评估全部选择。超支或违反规则的草稿无法确认。已确认的命谱会存档，并在重生后保留。

## 饮食与休息

口味只作用于品质修正后基础舒适度为正的食物。口味恩赐为匹配食物增加+4；口味负契使分类外的食物减少3，结果可能变为负数。基础值为零或负数的食物保持原值。口味只调整舒适度，不触发食用动作或限时增益。

食物分类使用`isekaiexpansion:fate_balance/meals/`下的物品标签：

| 口味组合 | 标签后缀 | 食物 |
| --- | --- | --- |
| `garden_palate` / `garden_bound` | `fresh_produce` | 新鲜蔬果 |
| `hearth_palate` / `hearth_bound` | `bread` | 面包 |
| `coastal_palate` / `coastal_bound` | `cooked_fish` | 熟鱼 |
| `root_palate` / `root_bound` | `carrots` | 胡萝卜食物 |
| `spice_palate` / `spice_bound` | `spicy_foods` | 辛辣食物 |

口味调整后，正值食物按[舒适度](/zh-cn/wiki/comfort/)的6种近期食物记录计算重复进食。此前出现0、1、2及至少3次时，通常分别保留1.00、0.70、0.40和0.10。饮食特质只调整重复食物的保留比例，最高1.00。正结果向下取整，至少保留1；负结果不受重复进食削减。之后应用性格修正，食物提示使用同一套计算。

完成睡眠后，基础恢复取30与缺失舒适度70%的较小值并向下取整，再乘睡眠特质倍率并四舍五入。最后应用性格修正，舒适度限制在0–100。世界唤醒睡眠玩家时，只有已经睡够重置时间所需时长的玩家能获得恢复。

## 其他联动

战利品与适用的任务奖励须经过IsekaiCore经验事件，才会受到学习倍率影响。异界扩展直接发放的`isekaiexpansion:xp`任务奖励与等级药水绕过此事件。战斗经验保持原值。经验奖励会取整，小额奖励可能不变。

命运天平只改变每日战利品经验上限；家园休息效果独立管理战斗经验上限。每个受影响的上限每秒按当前等级重算，最后一项修饰移除时单独恢复一次默认上限。两条路径都不会清除已经使用的经验额度。详见[等级成长](/zh-cn/wiki/leveling/)。

性格影响非直接赋值的舒适度变化与衰减间隔。收益和损失取整，非零结果至少保留原方向的一点；直接赋值跳过倍率。面貌特质只作用于当前声望不高于−100的阵营。口才与魅力是不同的对话属性。食欲改变饥饿容量，不定义治疗倍率。

## 定义位置

命途与效果由模组注册。附属模组通过[命运天平API](/zh-cn/dev/fate-balance-api/)扩展；数据包可以修改饮食标签和[食物舒适度数值](/zh-cn/wiki/comfort-food/)。
