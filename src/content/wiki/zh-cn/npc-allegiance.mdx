隶属让玩家获得普通 NPC 的指令权限，与好感分别计算。建立隶属不会增加好感、缔结婚约，也不会让平民获得战斗能力。

## 契约条款

| 规则 | 数值 |
| --- | --- |
| 普通项圈 | 需要信任 |
| 暗魔法项圈 | 目标生命值不高于 25% |
| 唯一 NPC | 无法建立隶属 |
| 已婚或已有隶属的 NPC | 无法再建立隶属 |
| 项圈或契约交互 | 距目标不超过 4 格 |
| 竞拍时长 | 1200 ticks（60 秒），按服务端运行时间计 |
| 起拍价 / 加价 / 最高价 | 8 / 4 / 60 绿宝石 |

## 建立隶属

对符合条件且信任你的 NPC 使用隶属项圈，或对符合条件、生命值较低的 NPC 使用暗魔法隶属项圈。成功后消耗项圈。正在跟随其他玩家的 NPC 无法建立隶属。新随从会原地待命；队伍有空位时，可命令其同行。

隶属契约经纪人为已加载且可选择的基础种族提供市民和战斗冒险者两类契约。普通库存和竞拍轮换排除不可选择的进化种族，包括 `isekaiorigins:raevyx`。物品提示会注明种族与职责。使用后，在附近安全位置生成对应角色并消耗契约。冒险者初始配备铁剑，具备战斗能力；市民保留平民行为。每位经纪人每天对每个种族、每种职责和隶属类型各提供一次购买机会。

| 招募职责 | 普通契约 | 暗魔法契约 |
| --- | --- | --- |
| 市民 | 32 绿宝石 | 48 绿宝石 |
| 战斗冒险者 | 48 绿宝石 | 64 绿宝石 |

## 指令与转让

所属玩家的对话菜单提供交谈、相处、移动指令、装备管理和解除隶属。指令轮盘使用专门的隶属回应。所有随从指令均有使用权限，但仍受队伍容量、寻路和 NPC 战斗能力限制。其他玩家无法通过对话或收纳卷轴夺取控制权。

对自己的随从使用相同隶属类型的空白契约，即可办理转让。NPC 会离开世界，已签订的契约则持有一次性凭证。兑现保留该 NPC 的职责、身份、外观和装备。兑现凭证的玩家成为新的所属玩家；已经兑现的凭证即使被复制，也无法再次使用。普通收纳卷轴保留原有归属，不能转让隶属。

选择解除隶属并确认后，随从停止跟随，指令权限恢复为普通关系规则，好感保留。解除不会返还项圈或契约；NPC 已收纳到契约时，需要找回该契约才能取回 NPC。

## 竞拍与退款

每位经纪人提供一个共享拍品，注明种族以及市民或战斗职责，中标契约保留对应职责。出价会按当前报价从背包扣除绿宝石并暂存。更高出价会将上一位竞拍者的款项计入退款余额。当前领先者不能给自己加价。过期报价会被拒绝并刷新。

竞拍结束后，中标者可向该经纪人领取契约。中标拍品跨重载保存，领取后才出现下一件拍品。被超价的玩家可向任意经纪人领取退款，每次最多 64 绿宝石。背包已满时，交付物会掉落在附近。无人出价的过期拍品在下次查看时轮换。

## 与关系系统的交互

| 系统 | 隶属规则 |
| --- | --- |
| 好感与赠礼 | 独立变化；隶属不等于信任 |
| 婚姻 | 解除隶属前，随从不会接受求婚 |
| 装备 | 所属玩家可管理双手装备与背包 |
| 随从队伍 | 沿用容量与玩家会话规则 |
| 对话 | 两种隶属类型均覆盖当前全部 18 个种族 |
