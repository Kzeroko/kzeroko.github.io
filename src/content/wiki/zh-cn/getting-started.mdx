异界扩展为 KenToMahou2（KTM2）整合包提供自定义 RPG 系统。先了解按键、角色选择和当前资源，再在接触相应装备或内容时查阅链接中的指南。

## 设置操作按键

以下是本模组的默认绑定。你的控制设置或整合包保存的选项可能使用不同按键。

| 默认按键 | 操作 |
| --- | --- |
| K | 打开主动技能界面。 |
| 左 Alt，短按 | 施放技能栏当前准备好的技能。 |
| 左 Alt，按住并滚轮 | 浏览技能栏；松开只保留选择，不立即施放。 |
| 左 Alt，双击 | 在允许打开时呼出随从指令轮盘。 |
| J | 打开任务界面。 |
| U | 打开表情界面。 |
| 未绑定 | 装备技能激活；使用手动激活路径前先分配按键。 |

技能键会短暂等待，以区分短按和双击。选中技能不会绕过解锁、冷却或资源要求；某些界面和动作限制也会阻止激活。详见[技能树](/zh-cn/wiki/skill-tree/)与[装备技能](/zh-cn/wiki/equipment-skills/)。

## 理解角色选择

[命运天平](/zh-cn/wiki/fate-balance/)组合恩赐与负契。默认初始预算为 10 点，由服务端控制；确认前应查看效果与冲突。

[种族、职业与技艺](/zh-cn/wiki/identity/)是独立身份层。可选内容和晋升条件由已加载内容决定。应查看目标选项显示的要求，玩家等级并不能满足全部晋升条件。

[命运轮环](/zh-cn/wiki/skill-tree/)是另一套成长界面。玩家升级会增加主技能树点数，各节点还可以拥有自己的要求。

## 区分成长轨道

| 轨道 | 查阅方向 |
| --- | --- |
| 玩家等级 | [等级与经验](/zh-cn/wiki/leveling/)中的经验和技能树点数。 |
| 装备等级 | 通过锻造石成长；普通武器使用并不是文档所述的升级途径。 |
| 冒险者阶级 | 声望要求与明确晋升，独立于玩家经验。 |
| NPC 好感 | 绑定玩家与 NPC 身份的关系门槛。 |

装备还另有[技能解锁与觉醒](/zh-cn/wiki/equipment-skills/)、[宝石镶孔](/zh-cn/wiki/gems-and-sockets/)和[蓝图锻造](/zh-cn/wiki/forgery/)系统。镶孔、物品等级和觉醒技能不是可以互换的升级；拿到相关材料或装备时，可查阅对应指南。

## 留意战斗资源

星界能量是具有上限和回复速度的当前储量。盾牌另用盾势：格挡会消耗盾势、暂停恢复，并可能破防。[属性与状态效果](/zh-cn/wiki/attributes-and-effects/)解释数值，[状态效果目录](/zh-cn/wiki/status-effects/)说明限制、恢复增益和清除规则。

部分生物带有元素数据。应把来袭伤害类型与**目标的**[元素](/zh-cn/wiki/elements/)匹配；未分配元素的生物不受元素倍率影响。多个弱点和抗性会组合计算，因此不能概括为统一的 ±25% 修正。

## 准备恢复的场所

[舒适度](/zh-cn/wiki/comfort/)记录饮食变化、受伤、睡眠和环境条件。家附近的遮蔽环境可在指南列出的条件下抵消自然衰减；任意位置放置屋顶并不保证有效。舒适度指南列出条件和各档位影响。

[我的家园](/zh-cn/wiki/my-home/)介绍认领已识别空间、成员、家具与符合条件的睡眠收益。[寻路](/zh-cn/wiki/wayfinding/)介绍地标和导航，[地形](/zh-cn/wiki/terrain/)说明生成世界及其设置。

## 接下来查什么

- 遇到不熟悉的蓝图或砧台交互时，查阅[蓝图](/zh-cn/wiki/blueprints/)和[锻造](/zh-cn/wiki/forgery/)。
- 想了解与阵营的关系时，查阅[声望](/zh-cn/wiki/reputation/)。
- 想辨认 NPC 的表情时，查阅[NPC 情绪](/zh-cn/wiki/npc-emotions/)。
- 制作内容时，从[任务数据](/zh-cn/wiki/quest-data/)、[对话数据](/zh-cn/wiki/dialogue-data/)或[法术数据](/zh-cn/wiki/spell-data/)开始。

这些页面记录已核对的仓库状态。服务端配置、数据包和依赖版本可能改变可用内容或数值；依赖的版本限定说明会标在所属页面。
