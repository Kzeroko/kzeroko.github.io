A mob's element determines which incoming damage categories deal more or less damage. The relation belongs to the defender, so a Fire weakness does not imply an inverse weakness on the attacker.

## Reading the relation

A matching weakness multiplies damage by 1.25; a matching resistance multiplies it by 0.75. A mob with no assigned elements receives no change from this rule. These relations apply to mobs with element data, not automatically to every player who casts an elemental spell.

The table uses exact damage keys to distinguish ordinary fire from Fire spell damage, ordinary lightning from Lightning spell damage, and ordinary melee from the physical-melee spell school. Spell damage is classified by its registered school first. A healing-school entry here concerns **damage** attributed to that school; it does not turn normal healing into an attack.

## Complete relation table

| Target element | Weakness: receives more damage | Resistance: receives less damage |
| --- | --- | --- |
| Common | `spell_astral` | — |
| Dragon | `dragon` | Every key except this row's weaknesses |
| Shard | `spell_soul`, `explosion` | `trident`, `cactus`, `melee`, `spell_earth` |
| Arcane | `spell_arcane`, `spell_astral` | `magic`, `spell_physical_melee` |
| Fire | `spell_water`, `spell_frost` | `spell_fire`, `fire`, `spell_wind`, `explosion` |
| Water | `spell_frost`, `lightning`, `spell_lightning` | `fire`, `spell_fire`, `spell_water`, `melee` |
| Frost | `melee`, `execution`, `fire`, `spell_fire`, `lightning`, `spell_lightning` | `spell_frost`, `spell_wind`, `spell_water` |
| Wind | `fire`, `spell_fire` | `cactus`, `spell_lightning`, `lightning` |
| Earth | `explosion`, `spell_earth` | `trident`, `cactus`, `melee`, `generic`, `spell_wind`, `lightning`, `spell_lightning` |
| Lightning | `spell_earth`, `spell_wind` | `wither`, `dragon`, `spell_soul` |
| Soul | `spell_light`, `spell_dark`, `spell_healing` | `spell_soul`, `execution`, `melee`, `cactus`, `generic`, `spell_astral` |
| Astral | `spell_soul` | `spell_light`, `spell_dark`, `spell_arcane` |
| Light | `spell_dark`, `wither` | Every key except this row's weaknesses |
| Dark | `spell_light`, `spell_healing` | Every key except this row's weaknesses |

Dragon, Light and Dark resist every classified key outside their listed weaknesses, including keys not otherwise named in the table. The lists describe Expansion's registrations; another mod can extend the shared registry.

`dragon` is dragon-breath damage; `cactus` also includes sweet berry bushes. `fire` uses the fire damage tag, `explosion` the explosion tag, and `lightning` lightning-bolt damage or the lightning tag. Unmatched non-spell sources fall back to `generic`. Unlisted spell schools receive their own school-derived key, which can still be resisted by an “every key except” row.

## Multiple elements

Count matching weaknesses as `E` and matching resistances as `R` across the target's distinct elements. The weakness multiplier is `1.25 + (E - 1) × 0.10` when `E > 0`, otherwise 1. The resistance multiplier is `max(0, 0.75 - (R - 1) × 0.10)` when `R > 0`, otherwise 1. Multiply both results.

| Matches | Element multiplier |
| --- | --- |
| 1 weakness, 0 resistances | 1.25 |
| 2 weaknesses, 0 resistances | 1.35 |
| 0 weaknesses, 2 resistances | 0.65 |
| 1 weakness, 1 resistance | 0.9375 |

For example, Fire spell damage against a mob carrying Fire and Frost finds Fire resistance and Frost weakness. The combined multiplier is `0.75 × 1.25 = 0.9375`. This is only the elemental stage; armour, attributes, talents and other damage rules can still alter the final result.

The element names and set-backed registry were checked in local IsekaiCore source for the configured `0.4.0-build60`. The relations and multiplier formulas are implemented in Expansion.
