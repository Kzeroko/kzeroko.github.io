每个游戏内开发编辑器都是叠在一台自由旁观相机上的同一个工作区：面板在四周，中间是实时的世界。你用鼠标和移动键驾驶相机，玩家本体留在原地。在世界里点击可以拾取方块、实体和编辑器辅助线，坐标靠指，而不是靠手敲。

## 它做什么

工作区负责布局、配色、视口相机、拾取、快捷键和状态栏。各编辑器只提供自己的侧栏、检查器、工具栏工具，以及可选的底部停靠栏。实现位于 `client.editor`，属于内部代码：没有公共 API 外观类，服务端校验仍由各编辑器自己的数据包负责。

| 编辑器 | 基于 | 打开方式 |
| --- | --- | --- |
| 地下城门扉、地下城脚本触发器、地下城门扉解锁序列、地下城战利品箱 | 方块编辑器 | 使用放置好的方块 |
| 公会接待员、结构空间、结构工坊 | 方块编辑器 | 使用放置好的方块 |
| 场景触发器 | 方块编辑器 | 使用场景触发器方块 |
| 场景录制器 | 带时间轴停靠栏的工作区 | `/ise dev scene editor`，或触发器编辑器的 **录制** 工具 |
| 镜头规划器 | 带时间轴停靠栏的工作区 | `/ise reel` 或 `key.isekaiexpansion.shot_planner` |

[场景编辑器](/zh-cn/dev/scene-editor/)和[镜头规划器](/zh-cn/dev/shot-planner/)页面分别说明各自的面板与按键。

## 运行时模型

### 布局

| 区域 | 尺寸 | 内容 |
| --- | --- | --- |
| 工具栏 | 26 dp 高 | 强调色竖条、标题与副标题、编辑器工具，以及相机复位、提示、隐藏、配色和关闭 |
| 侧栏 | 136 dp 宽 | 分区列表或大纲 |
| 视口 | 剩余空间 | 渲染出的世界；面板没有接住的输入都会交给相机 |
| 检查器 | 252 dp 宽 | 当前选择的字段 |
| 停靠栏 | 由编辑器决定 | 场景录制器和镜头规划器的时间轴 |
| 状态栏 | 16 dp 高 | 状态信息、导航提示和相机读数 |

读数每 120 ms 刷新一次，显示位置、偏航、俯仰、翻滚、视野和飞行速度。**隐藏**（`H`）会收起全部面板，只留一个 **显示界面** 按钮，整个窗口都成为视口。重建面板时会保留它的滚动位置。

### 视口相机

打开编辑器时，视口相机从你当前的视角开始，焦点放在准星对着的方块或实体上（2–48 格远），没有目标时放在前方 8 格。随后方块编辑器把相机转向它的方块，场景录制器转向已绑定的触发器，并以该方块为焦点；只有与它的距离超出 2–12 格时，相机才沿视线前后移动。只要有编辑器开着，视角就切到第三人称，让你的身体留在原地渲染（相机在身体里面时除外），HUD 同时隐藏。最后一个占用相机的系统松手后两者都会恢复，除非你在此期间自己改过。

| 输入 | 作用 |
| --- | --- |
| 左键拖动 | 绕焦点环绕 |
| 左键单击 | 拾取：按编辑器不同，可拾取辅助线、方块或实体 |
| 右键拖动 | 原地环视；按住期间移动键用于飞行 |
| 中键拖动、`Shift` + 左键拖动 | 在视平面内平移 |
| `Alt` + 左键拖动、`Shift` + 中键拖动 | 环绕 |
| 滚轮 | 向焦点推近或拉远 |
| `Shift` + 滚轮 | 精细推拉，每格四分之一步 |
| `Alt` + 滚轮 | 视野，每格 2 度 |
| `Ctrl` + 滚轮 | 翻滚，每格 2 度 |
| 右键拖动时滚轮 | 飞行速度每格 ×1.2 |

左键按下后光标移动超过 4 像素才变成环绕；在此之前松开就算单击。拖动期间光标被捕获，旋转不会卡在窗口边缘，松开后光标回到按下的位置。鼠标位移从按下的那一刻开始计算。拖动进行时，无论被捕获的光标在哪里，滚轮都作用于相机，面板也不会响应指针。

| 飞行输入 | 效果 |
| --- | --- |
| 前、后、左、右移动键 | 沿视线方向及其两侧飞行 |
| 跳跃键或 `E` | 上升 |
| 潜行键或 `Q` | 下降 |
| 疾跑键 | 速度 ×3 |
| `Alt` | 速度 ×0.25 |
| `Z` / `X` | 以每秒 45 度向左 / 向右翻滚 |

飞行的加减速约 0.09 秒，滚轮推拉约 0.07 秒。焦距保持在 0.35–512 格，视野在 10–130 度，俯仰在 ±89.9 度以内。移动键跟随你的按键绑定；按扫描码绑定的键不能飞行。每个编辑器打开时使用偏好文件里的 `fly_speed`。滚轮改动的速度只在该编辑器关闭前有效，每次改动都会显示在状态栏。

### 拾取

单击时，从当前渲染的相机穿过光标发出一条最长 160 格的射线。比第一个命中的方块更近的最近实体优先；否则取方块。包住相机的实体会被跳过。绘制辅助线的编辑器会先用被点击那一帧的投影检查辅助线。

字段或按钮发起拾取请求后，下一次单击就用于这次拾取。状态栏会写明该点什么，按 `Esc` 取消。坐标字段旁的拾取按钮显示为 `⌖`。

### 相机优先顺序

有多个系统可以接管相机。每一帧在建立投影之前，会询问所有来源的姿态，取应答者中权限最高的一个：

| 权限 | 来源 |
| --- | --- |
| `SHOT_REEL` | 镜头卷播放，以及工作室里的镜头相机 |
| `SCENE_PREVIEW` | 场景录制器的相机轨道预览 |
| `SCENE` | 服务端过场场景、镜头动画场景和对话取景 |
| `EDITOR_VIEWPORT` | 自由视口相机 |

胜出的姿态为整帧设定位置、偏航、俯仰、视野和翻滚。翻滚直接旋转视图矩阵，所以相机翻滚时画面也一起翻滚。镜头卷、场景预览和视口的姿态是稳定姿态：会跳过视角摇晃和受伤倾斜。任一姿态胜出时都会隐藏方块轮廓；相机落在某个玩家的碰撞箱内（各方向外扩 0.1 格）时，这一帧不绘制该玩家。因此相机在你眼睛位置或穿过身体时，看到的是世界而不是模型内部。高权限来源占用相机时开始拖动视口，会先接过那一帧的姿态，导航从你正看着的画面继续。

其他模组可以在渲染线程上通过 `net.kzeroko.isekaiexpansion.api.client.camera.CameraDirectorAPI` 读取导演状态。`isDirecting()` 表示当前渲染的这一帧是否由某个姿态接管，`fov(double)` 按导演混合游戏自身视野的方式，把基础视野混合到该姿态的视野。每帧的姿态在世界渲染开始时确定，此后两个方法都针对当前帧作答。

### 偏好文件

配色与导航设置保存在游戏目录下的 `isekaiexpansion-deveditors.txt`，以 UTF-8 写入。

```text
# IsekaiExpansion developer editor preferences
format 1
theme blender
look_sensitivity 0.220
fly_speed 10.00
navigation_hints true
```

| 键 | 类型 | 默认值 | 作用 |
| --- | --- | --- | --- |
| `format` | `integer` | required | 必须为 `1`。其他值会把所有条目重置为默认值并重写文件。 |
| `theme` | `enum(blender, blockbench, graphite)` | `blender` | 编辑器配色，不区分大小写。未知名称保持默认值并重写文件。 |
| `look_sensitivity` | `number` | `0.22` | 每拖动一像素旋转的角度，限制在 0.04–1.2。无法解析时使用默认值。 |
| `fly_speed` | `number` | `10.0` | 每个编辑器打开时的飞行速度（格/秒），限制在 0.5–128。滚轮从不写入它。 |
| `navigation_hints` | `boolean` | `true` | 在状态栏显示导航提示。除 `false`（不区分大小写）外都视为开启。 |

以 `#` 开头的行、空行、未知键和没有值的行都会被忽略。文件不存在时使用默认值，不会主动写出。读取失败会记录警告并重写文件。每次写入都把全部六行写到同目录的 `.tmp` 文件，再移动到目标位置；文件系统支持时为原子替换，注释和未知键不会保留。

**配色** 按 Blender、Blockbench、Graphite 循环，并重建当前编辑器。其他编辑器在下次打开时使用新配色。

## 约定

- **线程**：片段与视图代码运行在 ModernUI 线程，世界、网络和相机状态属于客户端线程。工作区的 `onMain` 和 `onUi` 用于在两者间切换。拾取结果会回投到 UI 线程；导航接管回调运行在客户端线程。
- **快捷键**：只有在没有文本框获得焦点、也没有正在进行的视口拖动时，工作区才会先于各视图读取按键。`H` 切换面板显示，`Shift+C` 把相机放回你的眼睛位置。
- **Esc**：先取消正在进行的拾取，再让编辑器有机会退出预览之类的模式，最后才关闭界面。物品栏键不再关闭编辑器。
- **编辑**：文本和数字字段在输入时立即提交每个有效值，从不重建面板，焦点不会丢失。选项和开关会重建检查器，因为它们通常会改变显示哪些字段。
- **释放相机**：关闭编辑器会释放视口相机；即使拖动尚未结束，光标也会恢复。断开连接同样会释放。
- **输入**：拖动位移和按键变化取自游戏的鼠标回调，而不是轮询光标位置。第三方模组 Ixeris 4.6.8 在自己的线程上轮询输入，捕获光标后，它的缓冲原始输入只把移动送进这些回调，轮询到的位置保持不变。拖动时的滚轮同样取自滚动回调。在下一帧之前就松开的按下仍算单击。

## 扩展方式

新的方块编辑器继承 `BlockEditorFragment`，新增一个 `BlockEditorKind` 常量，指明哪些方块的世界辅助线随它显示，再通过 `BlockEditorController.open` 打开：

```java
public final class BeaconEditorFragment extends BlockEditorFragment {
    private double radius;

    public BeaconEditorFragment(BlockPos pos, double radius) {
        super(BlockEditorKind.BEACON, "Beacon", pos);
        this.radius = radius;
    }

    @Override
    protected List<String> sections() {
        return List.of("Range");
    }

    @Override
    protected void buildSection(EditorForm form, int section) {
        form.number("Radius", radius, NumberSpec.DISTANCE, value -> radius = value);
    }

    @Override
    protected void save() {
        var value = radius;
        onMain(() -> ConfigureBeaconPacket.send(pos, value));
        close();
    }
}
```

方块编辑器会在侧栏列出分区，显示所属方块坐标和 **聚焦方块** 按钮，并额外提供 `Ctrl+S` 保存、`F` 聚焦方块、`1`–`9` 切换分区。`pickRelativeBlock` 请求点击一个方块，并返回它相对编辑器方块的偏移。任何工作区都可以重写 `focusPoint()`，指定打开时相机转向的世界坐标；方块编辑器返回自己方块的中心。

`EditorForm` 负责生成检查器的各行：

| 方法 | 生成的行 |
| --- | --- |
| `text` | 带标签的单行文本框 |
| `number`, `integer` | 数字字段，拖动标签即可改值 |
| `vec3`, `blockPos` | 标题下的三个坐标轴字段，可带拾取按钮 |
| `choice` | 三个以内的选项横排显示，更多则弹出下拉列表 |
| `toggle` | 开关按钮 |
| `listItem` | 整宽的大纲条目 |
| `button`, `primaryButton`, `dangerButton`, `actions` | 按钮与按钮行 |
| `section`, `hint`, `readout` | 小标题、灰色说明和只读值 |

`NumberSpec` 决定数字字段的范围和拖动速率：每拖动一像素增加 `step`；按下时按住 `Shift` 精细十倍，按住 `Ctrl` 粗略十倍。整数规格会把每次修改取整。

选项值依次在 `screen.isekaiexpansion.developer_editor.`、`screen.isekaiexpansion.shot_planner.`、`screen.isekaiexpansion.cinematic_scene.editor.`、`screen.isekaiexpansion.dungeon.editor.` 下的 `option.` 键中查找译文；都找不到时，把值里的下划线换成空格并将各单词首字母大写。

## 验证方式

- 逐个打开编辑器：方块编辑器转向它的方块，场景录制器转向已绑定的触发器，镜头规划器保持你的视角；相机在你眼睛位置时看不到自己的身体，飞离后身体照常渲染；关闭后 HUD 恢复。
- 安装 Ixeris 时，用每个鼠标键拖动，确认相机跟随鼠标的全部移动。
- 依次试环绕、环视、平移、推拉、翻滚和变焦；用每个移动键飞行，并配合疾跑键和 `Alt`；确认光标回到按下的位置。
- 分别拾取方块、实体和你自己；在拾取过程中和拖动过程中按 `Esc`。
- 修改配色和灵敏度，重启客户端后检查文件是否保留。用滚轮改变飞行速度后重新打开编辑器，确认它又从文件里的 `fly_speed` 开始。再测试错误的 `format`、未知配色和无法解析的数字。
- 在服务端过场场景播放时、以及镜头卷预览运行时打开编辑器，确认在你拖动前高权限来源一直占用相机。
