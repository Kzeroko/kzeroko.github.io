`WorldGateAPI`是永久传送门的服务端门面。每个隐形锚点保存外观设置，并重建一个传送门实体；世界存档保存双向配对。共用渲染器沿用原有材质层，把传送门绘制在固定的世界平面上。

## 它做什么

`isekaiexpansion:world_gate`取代已移除的基座。它没有生存掉落、配方、碰撞或活塞移动。创造模式管理员可用`/give @s isekaiexpansion:world_gate`获取物品，放置后打开共用开发编辑器。辅助标记遵循现有开发编辑器的显示偏好。

世界之门遗迹沿用现有地表结构、地形选址与预留系统。起始池等权选择六份原生模板。Conquest砌体、残拱、巨石与圆环围绕两侧畅通的入口布置。选址配置位于`data/isekaiexpansion/`下的`worldgen/structure_set/world_portal_ruins.json`，起始池位于`worldgen/template_pool/world_portal_ruins/start.json`。生物群系标签将自然生成限制在适合的主世界陆地群系。

六种遗迹各有独立构图：风化门楼、分裂巨石、植被侵覆的神庙圆盘、哥特式残墙、圣所庭院，以及带弯曲支撑的断裂圆环。Atelier编写源使用Conquest原生柱身、柱头、檐口与局部砌体形状。`tools/worldgate/ruins-manifest.json`记录第2版、原生模板哈希、边界与锚点设置；重建美术资源时应与导出的模板一同更新。传送门材质渲染与这些结构资源相互独立。

独立遗迹使用拼图`size: 1`；地表结构编解码器接受`1–30`并拒绝`0`，因为Minecraft 1.20.1会在深度为零时产生空起点。选址使用`spacing: 144`与`separation: 127`区块：标称间距2304格，起点中心至少相距2048格，当前模板旋转后的锚点间距超过2000格。全部16次尝试都留在同一个有限区域内。地形或避让导致区域没有遗迹时，间隔会增大。

ReTerraForged地形单元提供自然高度与地形分类。KTM2预留24格半径的平整核心和16–64格的过渡带，至少高出水线2格，核心起伏超过24格时拒绝选址。共用预留流程使地点避开已塑形地貌和其他结构。高空与地下地貌区域只在实际占地区域内阻止地基平整；区域外的普通地面可承载传送门或公会地基。生成、原版定位与模组搜索复用同一个重新选定的起点。

## 运行时模型

方块实体在服务端登记位置，每20刻（1秒）核对并重建不独立存档的传送门实体。UUID由维度与方块位置推导，因此复制模板不会复制运行时身份。已加载的门不持有永久区块票据。删除锚点会解除存档中双方的连接；修改频道也会解除配对。

| 限制 | 数值 | 作用 |
| --- | --- | --- |
| 接触蓄力 | 40刻（2秒） | 持续接触有朝向的门面后开始准备旅程。 |
| 自然配对距离 | 1024–8192格 | 锚点间的水平距离；适用于空频道。 |
| 并发旅程 | 每世界2个 | 其他玩家保持接触时等待空位。 |
| 区块请求 | 每旅程每刻2个 | 轮询完成状态，不等待future阻塞线程。 |
| 区域决策 | 每旅程每刻1个 | 复用考虑地形的结构选址计算器。 |
| 旅程超时 | 1200刻（60秒） | 失败后释放临时票据。 |
| 重试间隔 | 200刻（10秒） | 旅程结束后仍保持接触时生效。 |

首次使用优先寻找已有搭档，其次选择已登记的未配对门，最后搜索自然遗迹。配对为一对一，保存在世界的`isekaiexpansion_world_gates`状态中。搜索仅对主世界中的空频道门运行。具名频道可连接同一维度中已登记的门，不受自然距离限制；每组预定配对使用独立频道，测试前先加载两端。一个频道超过两个锚点时，会随使用形成多组独立配对。

离开门面、断线、死亡或切换维度都会取消目的地准备。传送会检查两侧是否有支撑、干燥且能站立的净空。落点受阻时失败，不修改地形。骑乘状态无法蓄力；传送冷却避免立即返回。接触门面还会更新全局传送魔法使用的世界之门共鸣锚点。

## 约定

在服务端线程调用门面。同一位置与频道的重复登记不会改变结果。编写数据由`WorldGateSettings`承载；配对属于运行时数据，不能复制进模板。宽、高、颜色与环境音通过实体追踪数据同步，朝向使用实体yaw。碰撞与显示使用同一有朝向的门面，并检查椭圆边缘。

编辑器把经过验证的设置发送给服务端。保存要求玩家是附近的创造模式管理员、锚点区块已加载、朝向为水平方向。无效数据包不会修改方块。存储设置格式错误时门保持停用，并保留原始错误数据，直到通过编辑器明确修复。缺失字段使用下表默认值，数值必须有限。设置读取器忽略未知NBT键。

| 字段 | 类型 | 默认值 | 作用 |
| --- | --- | --- | --- |
| `facing` | `enum(north, east, south, west)` | `south` | 定义门面法线的方块状态。放置时面向玩家，原生结构旋转与镜像会变换它。 |
| `Width` | `number` | `10` | 门面宽度，1–32格，以float NBT保存。 |
| `Height` | `number` | `10` | 门面高度，2–32格，以float NBT保存。 |
| `Color` | `integer` | `0xFF18DFFF` | ARGB打包整数，强制不透明。编辑器接受`#RRGGBB`，白色保持白色。 |
| `YawOffset` | `number` | `0` | 在朝向上叠加的局部角度，−180–180度，以float NBT保存。 |
| `FloorOffset` | `number` | `0` | 门面底部相对锚点的抬升量，0–16格，以float NBT保存。 |
| `Ambient` | `boolean` | `true` | 播放现有传送门环境音，NBT byte必须为0或1。 |
| `Channel` | `string` | `""` | 留空使用自然配对；否则最多64个小写字符，匹配`[a-z0-9_./:-]`。 |

## 扩展方式

未来地标可直接放入同一锚点，用开发编辑器配置外观，并在两侧留出足够地面。原生Jigsaw放置应加入`isekaiexpansion:atelier_editor_nbt`处理器：方块状态负责基本朝向，处理器在镜像时对局部yaw偏移取反。Atelier整包放置也使用该适配器。不保留旧基座别名或调色板版本兼容读取。

自然遗迹与公会使用同一地形融合和预留流程，显式避开村庄、公会、重生地标、要塞与营地。新增结构关系应写入共用选址数据，无需另建重叠检测器。IsekaiTweaks将`world_portal_ruins`登记为Atlas遗迹类别的主要兴趣点。

Atlas接入需要IsekaiTweaks中的两项资源：`data/isekaitweaks/atlas/interest_types/world_portal_ruins.json`中的服务端登记，以及`assets/isekaitweaks/atlas/styles/isekaitweaks.json`中以`isekaiexpansion:world_portal_ruins`为键、使用`ruins`图标的客户端样式。类别不会自动提供样式。缺少客户端样式时，即使服务端已经记录结构，地图标记和发现提示也都不会显示。

## 验证

检查Atlas时，在客户端与服务端安装重新构建的IsekaiTweaks，再以生存或创造模式走近自然生成的遗迹，确认发现提示和地图标记。旁观模式不会触发发现。检查jar是否同时包含上述两项资源；只更新异界扩展不会更新Atlas的登记或样式。

运行`./gradlew.bat -I tools/worldgate/verify.gradle checkWorldGates checkWorldGateGeneration`。离线检查覆盖设置拒绝、配对持久化与解除、朝向、门面接触、镜像变换以及六份已随模组提供的NBT锚点。生成检查通过Minecraft原生拼图代码组装每份模板，覆盖四种旋转、非空起点确认以及锚点最小间距。在Atelier目录运行`python -m unittest discover -s tests -p test_world_gates.py`，检查编辑器的类型化负载和遗迹导出几何。

运行`./gradlew.bat -I tools/terrain/verify.gradle -I tools/worldgate/terrain.gradle checkWorldGateTerrain`，用真实ReTerraForged地形单元测试启用和禁用KTM2地貌时的共用选址。测试覆盖三个种子、公会／村庄／原版敌对结构避让、重新选址后的定位候选、干燥地基及KTM2地基高度。测试夹具提供离线世界绑定；可选第三方结构集与完整服务端mixin启动仍需在游戏内检查。

在新的临时世界中运行`/locate structure isekaiexpansion:world_portal_ruins`与模组定位命令，再正常探索遗迹，检查地形过渡与附近结构避让，并双向穿越一组门。重启时让两端分别处于未加载状态，再让两位玩家重复旅行；堵住全部落点，搜索中途离开，检查临时区块票据是否释放。旋转并镜像捕获的锚点，从两面测试，再在预定Sodium/Iris环境中比较天空、地形和水面背景下的材质。离线检查不能证明游戏内渲染或地形已通过验收。
