## 📖 About

This is **Kzeroko's Workshop**, my personal site and the official home of the **KTM2** modpack and the **Isekai Series** mods — wiki, codex and devlog, in English and 简体中文.

## 🛠️ Development

```bash
npm install
npm run dev      # localhost:4321
npm run build    # astro check, then build to dist/
```

Content lives in `src/content/{wiki,codex,blog,pages}/<lang>/`. Keep the same slug in both languages — the language switcher relies on it.

> 中文正文里句号要放在星号外面（`**先看图纸**。`），否则 CommonMark 不会闭合强调。
